# S-0489 Host page under configuration

## Goal

Bring back the host page and place it under configuration. In addition, add a way to change what host headers are accepted so that flai can be hosted from one or more custom domains without getting a host header rejection.

## Acceptance criteria
- [ ] The Host page is available from a link in the Configuration sub-menu in the nav rail
- [ ] The host page includes a way to update configuration that should accept different host headers so that flai can serve traffic through tunnels/domains
