## Decisions

- The turns are classified when flai measures a story's usage from its logs and stored per day on the story's usage as `usage.turns`, as S-0272 did with `empty_wakes` (ADR-0105); `flai stats` reads the items, never the logs. Reading the logs at every `flai stats` call is a cliff: measuring every logged story read-only took 73 s on this host, over 412 MB of logs. Stories measured before the release carry none until `flai serve agent usage --all --write` fills them in, on the operator's word.
- A turn is one assistant message, by its message id, of the session's own agent (no `parent_tool_use_id`) with at least one tool call. Over the 106 story logs to 2026-10-04 that is 8,522 turns, 80 per story, the epic's mean.
- Classes, first match wins:
  - test run: a Bash call runs a test, lint, or format tool by hand (`go test`, `go vet`, `gofmt`, `golangci-lint`, `vitest`, `svelte-check`, `eslint`, `prettier --check`, `markdownlint`, the `make` test and lint targets, and the scripts behind them). `flai test`, `flai verify`, and the close-out are the commands that replace them, and are not.
  - hand edit: an Edit, Write, or MultiEdit of a narrative (`wip/agents/S-nnnn.md`), a task, or a story file, or a Bash call that writes one (`sed -i`, `perl -i`, a script that writes it, a redirection, `tee`).
  - empty wake: every call is `wait_for_events` and each was an empty wake by ADR-0105.
  - ceremony: every call is ceremony: the MCP `inbox` or `item_move`, or a Bash call whose every command is one a story-loop command replaces (`git add`, `commit`, `status`, `log`, `diff --stat`, `show --stat`, `rebase --continue`; `flai stream sync`, `stream log`, `stream open`, `move`, `touches`, `check`). The story-loop commands themselves (`task done`, `story start`, `stream state`, `criteria tick`, `test`, `verify`) are not ceremony.
  - work: the rest.
- ADR-0116 records the classes as proposed rather than accepted, so it can still change if TH-0278 asks for a `waits` class.
- The classes are not tuned to reproduce E-0017's figures. Doing so would count waits that woke on a change as empty wakes, and test commands named in heredoc text as test runs. The comparison is recorded in the story's notes, and criterion 3 waits for the designer on TH-0278.
- TH-0278, answered 2026-10-07T14:56:27Z: the operator confirmed the orchestrator's recommendation. The classes stay as defined, with no `waits` class. Criterion 3 now asks for the comparison and an explanation of each class that differs by more than ten percent, not for agreement. The operator reworded and ticked it.

Layer 2: T-1158 (the `flai stats` report) and T-1160 (the comparison with the epic's evidence), both after T-1157 and with no path in common, so they run together.
