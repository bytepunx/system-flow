# S-0170 The Operator can stop agents

## Context

The activity page shows each agent flai serve started, but nothing stops one: a stuck agent runs on, detached, across flai serve restarts. The operator stops it from the activity page, after confirming. Agents are started by `flai/internal/serve` (`agents.go`, `start.go`, `restart.go`), recorded in `serve/agents.json`, and started from the dashboard through the host methods `agent.start`, `agent.restart`, `agent.commit` (`flai/internal/hostapi/writes.go`), which run `flai serve agent <verb>`.

## Decisions

- Stopping is a method of the existing `agent` host action, not a new action: whoever may start an agent from the dashboard may stop it.
- A stop signals the process group (SIGTERM, then SIGKILL after a grace period) only while the PID is still the agent's: a session leader whose start in clock ticks since boot is the one recorded with the run (T-0605). A PID reused since, after a reboot, is left alone and the run is only recorded as stopped (I-0025: kill by PID, never by pattern, and never a PID that is not ours).
- The first cut compared wall-clock start times, worked out from `btime`, within ten minutes. On WSL2 `btime` moves when the host sleeps, so it could refuse to stop a real agent. T-0605 records the process's start in clock ticks at launch and compares it exactly. ADR-0058 was corrected in place: it has not reached main, and it described the first cut.
- `settleOrphans` and the start, restart, and commit refusals use the same test (T-0605): the story's goal names agents that persist across machine restarts, and a reused PID is what kept such a run live. This was first raised as an open question; it is in the story's scope, so it was done rather than asked.
- A stopped run gets the outcome `stopped` and reads on the dashboard as failed, with why "stopped by the operator": the story is left where it is with no agent, which Retry or a move back to ready answers, as for a failure. No new dot colour.
- A run that ended waiting for an answer can be stopped too: it is recorded stopped, so an answer does not start it again.
