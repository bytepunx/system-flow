## Decisions

- Applied TH-0588's answers (confirmed by flai serve 2026-10-28, resolved 2026-10-31): the import instance lives in the imported repository, made by `flai import --formula` after the import's commit, with the check and `flai import test` as its steps; the cadence is a role step with `focus` defaulting to all three, then `flai issue list --report`, `in: main`, with `analysis.formula` in the manifest. Criterion 1 reworded to match; T-1785, T-1786, T-1789, T-2016, and T-2017 rewritten.
- T-2016 narrowed: S-0421 already reads an input's `default` and `flai formula run` takes it. What is left is the schedule check, and I-0249's template-test fix joins it (`flai/cmd/new_test.go`), since both new formulas use an input.
- `analysis.formula` is started behind the `analyze` host action, the analysis schedule's own, not `formula`; it runs `flai formula run` through `os.Executable` as the formula scheduler does (D-0459).
- Plan, three layers: T-2016 and T-2017 first, sharing no path. Then T-1785 after T-2017 (the host API switches to `--formula`) and T-1786 after T-2016 (its file declares a defaulted input and may be scheduled); they share no path. Then T-1789 after both, describing them. T-1787 and T-1788 wait on TH-0810, which asks to move the live runs to a follow-up story, as D-0461 did for S-0423.
- T-2016 and T-1786 both touch `check.go` and `check/formulas_test.go`, in different layers.
- Added T-2433 (second layer, after T-1785): the board's Import prompt still described the `--commit` flow (tests, then commit), which `import.run` no longer runs.
- Added T-2434 (third layer, after T-1786, beside T-1789): TH-0588 assumed `role_run` could start the built-in analyzer for a role step, but `serve.RunRole` refuses built-in roles and `flai analyze` refuses an agent flai serve started. So the cadence's first step, and any instance `analysis.formula` makes, could not be worked. Fixed here rather than in a follow-up, since criterion 2 asks for a role step that runs the analyzer. The analyzer starts through its own start, with the instance's focus, and the instance is recorded on the run (`instance`, not `item`, which serve uses to tell planner runs apart). Recorded as ADR-0245, refining ADR-0239.
- `flai issue list --report latest` resolves the newest report under `design/analysis`, so the listing step's words need no edit by the instance's agent (ADR-0239 forbids changing a step's words).
- `template/template.yaml` is left alone: the version is set at publish (D-0456).
- `analysis.formula` is set by hand for now: `flai manifest set` and the dashboard's analyzer settings panel do not write it.
- TH-0810, confirmed by the operator on 2026-11-02, applied as D-0461 was for S-0423. Criterion 4 is removed and T-1787 and T-1788 are cancelled. Both live runs move to the draft S-0564 in E-0024, `after: S-0424`, which holds their Work and criterion 4's words.
