- Criterion 4 (repeat the measurement with forks) moved to its own story, S-0241, in the backlog, on the designer's word on TH-0069 ("use rec"): forks are still refused headless (Claude Code 2.1.286, "Agent type 'fork' not found"). - I-0054's fix: a task is measured as the calls of the sub-agents started for it (`parent_tool_use_id`, matched to the `Agent` call whose description, else prompt, names the task's ID) plus an even share of the story's agent's own calls while it was in progress, split among the tasks in progress at once. Seen in S-0176's log: sub-agent calls share the story agent's session and carry `parent_tool_use_id` and `task_description`. The split keeps the agent's review and commit work on the task, which the sub-agent's calls alone would drop.
- Hence T-0712: the prompt and `delegation.md` ask the story's agent to name the task's ID in the sub-agent's description, so the match is reliable.
- Plan: layer 1 is T-0711 (`flai/internal/usage`, `flai/internal/serve`) and T-0712 (`flai/internal/harness`, both `delegation.md`), no path in common and neither needs the other; layer 2 is T-0713 (design, ADRs, issues), after both because it records what they built. Layer 1 runs at once, one task sub-agent each, in the story's worktree: they build different packages and neither tests the other's.
