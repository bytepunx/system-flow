# S-0041 Review and acceptance from the dashboard

## Context
The designer should be able to review a story in one place in the dashboard and accept it or send it back. Some of this exists: moving a story to done is acceptance with a confirmation that shows the release plan, blockers, and uncommitted files (S-0046, S-0050, S-0051: `AcceptConfirm.svelte`, `GET /api/items/:id/acceptance`, the move endpoint), and the item page sends a story back with a reason typed into `prompt()`. Missing: the diff of the story branch against main, a page that puts criteria, narrative, threads, diff, and plan together, acceptance recorded as the designer, progress while it runs, and failures shown as flai wrote them. flai has no diff command; `flai accept` logs only the merge and the push warning. Work is in `.flai-cache/worktrees/S-0041` on `story/S-0041`.

## Current state
All six tasks are done and all four acceptance criteria are checked. The work is one commit, `a9c9cd8`, on `story/S-0041` in `.flai-cache/worktrees/S-0041`; not pushed. `make flai-test` passes (golangci-lint 0 issues; behavior, integration, smoke; markdown lint); flaiover lint, svelte-check, 23 files and 147 tests, and a production build pass; `flai check --strict` is clean. The review page, the diff, a send back, a refused and a real acceptance were exercised through a container built from the branch, by API and in a browser, against a scratch project; the container is stopped and the image removed. A defect in `flai accept` found on the way is fixed here and recorded as I-0021. The operator's dashboard was not touched by the verification; its restart onto the S-0058 release is separate.
