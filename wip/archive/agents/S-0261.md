# S-0261 The MCP prime pack for a story is larger than Claude Code's tool result limit, so the agent reads it back from a saved file

## Context

I-0068: the MCP `prime` result for a story is 160 to 200 KB of JSON, and Claude Code saves any tool result over 50,000 characters to a file. This story's own prime reproduced it: 190,212 bytes.

## Current state

Every task is done. ADR-0104 pages the MCP `prime` result in parts of at most 40,000 bytes of JSON (`context.PartLimit`, `Pack.Parts` and `Pack.Part`); MCP `prime` takes `part` and `flai prime` takes `--part`. S-0205, S-0210, S-0211, S-0261, and the planner's pack for S-0261 now come in 5 or 6 parts, the largest 39,994 bytes. I-0068 is closed. The verifier's close-out passed every step to the commit step, which stopped for want of a message; its notes on findings outside the story (I-0073, I-0076, I-0078) are committed. Both criteria are ticked and S-0261 is in review.

## Decisions

- The plan's tasks stand as the planner wrote them. Layers: T-0986; then T-0987 and T-0989 together (no path in common, both wait only for the ADR); then T-0988 (calls what T-0987 builds); then T-0990 (closes the issue once T-0988's test passes and T-0989's documents describe the fix).
- Claude Code 2.1.290's limits, read from its binary: an MCP result over 25,000 tokens (`MAX_MCP_OUTPUT_TOKENS`, estimated at four characters a token) is refused, and any tool result over 50,000 characters is saved to a file. The 50,000 characters bind: the inbox at 49.5 KB was saved too.
- Paging, not trimming: the conventions alone encode to 71 KB for a story's agent, so no fix that keeps ADR-0049's never-cut conventions fits one result. Paging keeps every brief, so TH-0032 stands and no thread was needed.
- The part limit is 40,000 bytes, a fifth under 50,000 characters, measured as bytes, which are never fewer than the UTF-16 units Claude Code counts.
- ADR-0104, not 0102: S-0299 took 0102 and S-0301's branch has 0103. Accepted rather than proposed, since the plan asked for a thread only if the fix overrode TH-0032.
- `--part` implies `--json`: a part is what the MCP tool returns, and the text output stays the whole pack for a terminal. The ADR's two lines saying so were settled before T-0987 began, so nothing was built against the earlier wording.
- The pack's fields are `PartNumber` and `PartCount` (JSON `part` and `parts`): Go forbids a field and a method both named `Parts`.
- `docs/users/flai-reference.md` and the flag index in `docs/operators/settings.md` were regenerated with `make flai-reference` in T-0988, not hand-edited in T-0989, because a test checks them against the help.
- TH-0222 and TH-0226 (conflicts with S-0301 in `design/adrs/README.md` and `design/system/flai-cli.md`): each story adds its own index row and its own lines, so whichever is accepted second keeps both sides.
