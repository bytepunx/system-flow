After the fix: the eight pass, and the whole short suite from flai/ (go test -short -count=1 -skip '^TestGateway' ./...) passes with 0 failures with TMPDIR a symlink, as it does with a plain TMPDIR, 0 failures. So no other test compares a fake's $(pwd) with an unresolved temp path (criterion 2).

A first run there was discarded for it. go test writes its temp folders under /tmp in any ordinary run; the scratch folder is removed after the story's runs.
- The suite runs by hand with go test, against the rule that tests run through flai test, because flai test cannot set TMPDIR; it is the reproduction the story needs (D-0492). They ran with FLAI_STORY and FLAI_STARTED_BY unset, so that this session's variables did not reach the tests; flai guard refuses unsetting FLAI_AGENT, which was left as set.
