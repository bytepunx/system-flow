- `ready-empty` follows criterion 2's wording, the ready count below the in-progress limit's room, not the planner's empty column; T-2295 was rewritten to match.
- `draft-changed` holds on an edit of a story that is a draft after the edit, not only an edit of the `draft` field: a draft's words changing is what may make it ready to finalize. T-2293 was edited to match.
- T-2297 also touches `flai/internal/mcpserver/cursor.go`: `wait_for_events`' catch-up must pass the orchestrator's role so that a thread awaiting the operator reaches it.
- Thread events in a story-scoped inbox (`story_start`, `task_done`) are kept to the story's own threads, so they do not list what ADR-0179 only counts; `inbox` and `wait_for_events` report all.
- Deviation: `go test` was run by hand three times (one test with `-run`; the `mcpserver` package with `-timeout 560s`; it and main's copy without `-race`) because `flai test` named only the package when Go's 10-minute timeout fired. That showed no test hangs or slowed (I-0227).
