# S-005 flai new from template

## Context
flai new renders the template repository (design/system/template.md, ADR-0005) into a new directory. The template prototype is ./template with template.yaml, root/, and items/. Rendering rules: .tmpl files through Go text/template, layout folder rename on the first path segment, verbatim copy otherwise, no overwrite without --force. Sources are a local path or a git URL cloned into cache_dir/templates/<hash> by shelling out to git (ADR-0010). S-004 left a cobra tree with an app struct, config package, and in-process CLI tests to extend. First commit 38cb738 is on main.

## Decisions
- execx.Runner interface wraps git and docker so commands are testable; tests that need real git create a throwaway repo and skip if git is missing.
- Template cache key is sha256(repo@ref) truncated, so different refs of the same repo cache separately.
- Ref that is not a branch or tag falls back to a full clone plus checkout, so commit hashes work.
- Prompting happens only when stdin is a terminal and --defaults is absent; otherwise defaults apply and missing required variables are an error. Agents get deterministic behaviour.
- project_name defaults to the target directory name.
- Local template sources record their absolute path in the manifest; a `quote` function makes YAML scalars safe.
- items/ templates are read from the template cache, not copied into projects, until S-007 decides otherwise.

## Open questions
