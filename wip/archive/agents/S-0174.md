# S-0174 Pending releases are not worked out from a clone missing the remote's release tags

## Context

flai works out pending releases from local tags only. A clone whose `main` was fast-forwarded without the remote's release tags shows every story since its last local tag as unpublished and would publish versions the remote already has. The story makes flai ask the remote (`git ls-remote --tags`) and say so instead.

## Next steps

2. After acceptance, publishing from this clone asks origin for its tags first. If it says tags are missing, run `git fetch --tags origin`.

## Decisions

- When any component lags the remote, `publish.preview` offers no plan at all, not only the lagging component's: publishing is one run over every component and would be refused, so a plan with a Publish button would mislead.
- A remote that is configured but cannot be asked refuses a publish (it is still shown as a warning on the preview): the publish would have to push to it anyway, and refusing first changes nothing locally. A clone with no remote at all is not checked and publishes locally as before.
- The template component is not checked: its version lives in `template.yaml`, not a local tag.
- The remote's tags are kept for a minute per root and remote: the dashboard asks `publish.preview` on every item change. A stale remote answer can only miss a newer remote tag for that minute, never invent one.
- The dashboard hides archived done stories while the clone lags rather than flai asking the network on every board read (`board.get`, `flai board`, MCP `board`).
- `flai push --pending` with auto-publish refuses a lagging or unchecked clone too, dry run included: it would tag the same stale plan.
- `release.RemoteTTL` is exported so a test in `cmd` can turn the kept answer off; nothing else sets it.
- Items no plan covers (I-0024) are counted unpublished by `PendingIDs`, so the board keeps them on the done lane until a release boundary passes them.
- `story.component-tag` reads touches as `Holds.Claim` does (a component's name or tag is its path, open tasks' touches included) and skips research and experiment stories, which cut no release.
