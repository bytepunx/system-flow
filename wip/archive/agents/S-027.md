## Decisions
- Cost averaging is a running mean weighted by count, rounded to the minute; a bump without --cost keeps the average and increments the count.
- New instances are inserted before ## Remediation so the remediation text stays last; Close appends a dated line there.
- summary.md carries a "generated by" line; hand edits to it are overwritten by the next command, and check warns when it is stale rather than erroring, so a forgotten regeneration never blocks a commit.
- The good fixture has no issues folder: the folder is optional until the first issue, so new projects pass check without it.
