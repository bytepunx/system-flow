# S-0056 Estimates are written by the agent that pulls the story, in agent time

## Context
The operator asked on 2026-09-18 for estimates to be based on an agent implementing the work rather than on idealised human effort. When the story was queued, no work item here, active or archived, had an `estimate` field; the schema allows one, the metrics define estimate error, and the dashboard has an estimate versus actual chart, but nothing sets the field and no convention asks for it.

## Current state

They chose to cancel: estimates are not worth having for agent work at this scale. No tasks were written and no code changed. The branch `story/S-0056` had no commits and was removed with its worktree.

## Next steps
None. Archive with the next housekeeping.

## Decisions
