## Decisions

- Plan, reviewing the planner's seven tasks: the planner's second layer (T-2349 guard, T-2350 check, T-2351 command) cannot run together, since `flai/internal/check` imports `flai/internal/guard` and `flai/cmd` imports both, so each one's `flai test` builds what the other changes. They become a chain: T-2350 waits for T-2349 too, and T-2351 for T-2350. T-2353, the docs, now waits only for T-2348, whose ADR fixes the command's name, flags, and paths, so it runs beside the chain. Layers: 1 T-2347, T-2348; 2 T-2349, T-2353; 3 T-2350; 4 T-2351; 5 T-2352.
- The live trial (T-2348), run by hand in a scratch repository under `/tmp` with Claude Code 2.1.311 and `--model haiku`: a `.claude/agents/linkbot.md` that is a relative symbolic link to `defs/linkbot.md` is found and run with `--agent linkbot` and as a sub-agent through the Agent tool, as a regular file beside it is. With the link's target moved away, `--agent linkbot` is refused as not found, and the list of agents leaves it out, with no other error. So Claude Code follows the link, and a dangling link only hides the agent.
- ADR-0236 (refines ADR-0207 § 4): the generated definition lives at `.flai-cache/agents/<name>.md`, written by `flai role definition --write`; `.claude/agents/<name>.md` is a committed relative link to it that the operator makes once; the template ships no copy of the four. Rejected: a link to the role file itself (its description and tools sit under `definition`), committing generated copies (the double edit made mechanical), and flai making the link (a write under `.claude/` through the shell). D-0351 put this generation in its own story; D-0411 is the double edit it ends.
- T-2352's writes are the operator's (TH-0794): a symbolic link and a `git rm` cannot go through `permission_prompt`, and the conventions forbid writing `.claude/` through the shell.
- T-2347 (sub-agent): `roles.Generate`, `Generated.Agent`, `File`, `ParseAgentFile`, `Prompt` in `flai/internal/roles/definition.go`. A built-in role with model `inherit` and no agent model now leaves `model` out of `--agents`, as a defined role does. I fixed what it left outside its paths: `TestTheOrchestratorIsRefusedOnce` expected the removed refusal and now provokes a missing `verifier.md` instead; harness.go's duplicate `roleBody` became `roles.Prompt`.
- T-2349 (mine): the guard judges a built-in role by its generated tools, reading the manifest's design folder.
- T-2350 (sub-agent): the copy check is a warning, so plain `flai check` passes on a project made before S-0553 and `--strict` fails; tools compare in order; `name` is not compared.
- T-2351 (sub-agent): `--write` prints `mkdir -p .claude/agents` too when the folder is missing; `make flai-reference` regenerated the `--write` row of `docs/operators/settings.md`, agreed with S-0518 (MS-0278) and S-0420 (MS-0282) as generated.
- T-2423, added: the three template tests that read the four copies read the generated definitions, so the copies can go; three inert `planner.md` fixtures removed.
- The one flaky failure seen, `TestAHeldWaitFailsOnATruncatedStory`, is recorded as I-0244; the guard refusing sub-agents `flai role` reads as I-0245.
