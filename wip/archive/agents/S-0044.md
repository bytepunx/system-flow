# S-0044 Dashboard theme from the brand palette

## Context

## Current state
Complete for the revised palette (`#f7f3e3`, `#23b5d3`, `#119822`, `#645853`, `#054a91`). `src/routes/layout.css` defines the brand tokens for light and dark (ground, surface, raised, ink, ink-soft, muted, line, line-strong, primary, on-primary, accent, accent-strong, status quartet with soft fills) as CSS custom properties mapped to Tailwind utilities; dark is selected by `data-theme`, stamped before first paint from `localStorage` or the system preference and cycled by a navigation button (`src/lib/theme.svelte.ts`). No literal Tailwind palette class remains in routes or components; rendered markdown uses the same tokens. Chart palettes in `src/lib/viz/palette.ts` are brand-led and pass the dataviz validator in both modes against the new chart surfaces; state and nature slots were reassigned so the brand blue leads. `src/lib/theme.test.ts` parses the stylesheet and asserts 4.5:1 for eighteen text pairs and 3:1 for four control pairs per theme. Design Theme section with the token table and ratios; user note on the toggle. Verified by eye on the served build (board light and dark, charts dark). Story in review.

## Decisions
- `#23b5d3` reads at 2.2:1 and `#119822` at 3.4:1 on the cream ground, so light-theme text uses the darker steps `#17788c` and `#0c6e19`; the brand cyan and green fill indicators and badges with ink text. Recorded in the design table and asserted by the test.
- The revised palette has no dark colour, so the dark ground and surface are deep steps of the warm grey hue (`#191615`, `#272220`), keeping the warmth of the cream rather than a neutral black.
- The primary is a fill, not a text colour: white on `#054a91` (light) and `#0660bb` (dark) clears AA, and the dark primary clears 3:1 against the ground as a control; the wordmark uses the accent.
- Strong borders (inputs) were darkened to `#8a7d73` / `#7a685c` to clear 3:1 as control boundaries; card borders stay soft.
- Chart palettes keep six supplementary hues alongside the three brand families: two hue families cannot yield eight distinguishable, colour-vision-safe series, so the validator, not taste, fixed the steps.
- The theme toggle is a per-browser convenience in `localStorage`; the system preference is the default and nothing is written to the repository.
