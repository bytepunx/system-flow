## Decisions
- `app` struct passed to command constructors instead of package globals, so tests run the full tree in-process with captured stdout and stderr.
- Config Get/Set work on a JSON map with dotted keys and re-parse into the struct with unknown fields rejected, so the schema struct is the single definition.
- Save is atomic (temp file plus rename) so a crash mid-write never leaves a broken config.
- errcheck excludes fmt.Fprint* rather than sprinkling `_ =` across output code.
- `flai config path` added beyond the design table; useful for scripts. Design doc updated.
