## Decisions

- The planner's six tasks stand as drafted: the fix it proposes (the `sync` step passes over commits on main that change only `wip/` paths the branch does not change, and the close-out's last check calls `flai verify --sync-only`) fits all six of I-0119's instances that name wip-only commits, and still stops on an acceptance or a release.
- Layers: T-1375 alone (its ADR settles the rule the rest build and document); T-1377 and T-1379 together (Go in `flai/internal/verify` and the conventions share no path); T-1381 after T-1377 (its `--sync-only` runs the `sync` step T-1377 changes); T-1382 after T-1381 and T-1379 (the scripts call the flag, and T-1379's changelog entry names the script change); T-1383 last (the issue closes once the close-out no longer stops).
- T-1381 also rewrites the `sync` row of the step table in `docs/users/flai.md`, which it already touches.
- S-0341, in review, changes `story.go`, `verify.go`, and `close-out.sh` too; it is not on main yet, so this branch builds on main and keeps its edits narrow, to sync onto S-0341 when it is accepted.
- The rule judges the net change from the merge base to main (`git diff --no-renames --name-only HEAD...main`), not each commit: that is what acceptance merges (ADR-0135, alternatives).
- The sync step's note is a field of the step (`Step.Note`), not a `Report.Notes` entry: those are check findings, which `--record-issues` records as issues.
- T-1377's sub-agent named the function `verify.SyncOnly`, since revive rejects `VerifySync` as a stutter. It ran its real-git tests with `go test` in a scratch copy under `/tmp`, since `flai test` runs `-short`, where they skip; they passed. The close-out's integration tier runs them.
- T-1381's `make flai-reference` regenerated `docs/operators/settings.md` (one `--sync-only` row), which S-0232 claims; agreed on MS-0041 that the file merges cleanly.
- Closing T-1377 with the MCP `task_done` (installed flai 1.39.13) committed T-1379's paths too; recorded as I-0126, and T-1377's touches narrowed back.
- T-1382 was reproduced in a scratch clone of the repository with this tree's `bin/flai verify S-0347 --sync-only`: a commit on main to `wip/kanban/board.md` passed with a note naming it; a further commit to `README.md` stopped at `sync`, exit 1.
