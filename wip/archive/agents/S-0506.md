## Decisions

- The planner's seven tasks stand as written; reviewed against `cmd/mcp.go`, `cmd/mcp_http.go`, `mcpserver/permission.go`, and `mcphttp.go` on 2026-11-02.
- Layers, from each task's `after`:
  - Layer 1: T-2150, T-2151, T-2152. No `after`, no path in common, so they run together in the story's worktree. They share the Go package `cmd`, so each sub-agent is told that a failure outside its touches may be a sibling's half-done edit.
  - Layer 2: T-2160 (waits for T-2151, which changes `cmd/mcp_http.go` and `mcphttp.go` too) and T-2418 (waits for T-2152, whose `mcp.bind` it shows and whose `serve_actions.go` it changes).
  - Layer 3: T-2419 (waits for T-2150 and T-2160, which change `server.go` and `cmd/mcp_http.go`).
  - Layer 4: T-2167 (documents what every earlier task does).
- T-2151's recommended answer: over HTTP, `auto-approve` holds only for an agent whose name names a run `flai serve` started for the story the path belongs to. The check lives in `cmd` as an option function, since `mcpserver` does not import `serve` (D-0420). ADR-0243 records it.
- Criterion 1 names `stream_sync`, which is no MCP tool on either transport: `task_done` runs the sync as one of its steps. The parity test calls `task_done` over both, so the criterion is read as `task_done`'s sync step. No new tool was added.
- T-2152 also registered `flai serve mcp` in `cmd/serve.go` and added `serve mcp bind` and `clear` to the guard's host-configuration writers (ADR-0220). Its touches were widened to those three files.
- Container check, by hand on this WSL2 host with Docker Desktop 29.7.2, against a scratch project in `/tmp`: on the loopback default and on `0.0.0.0`, a container reached the server through `host.docker.internal` with 200 for the token, 401 without it, and 403 with an `Origin` header. A bind to WSL's `docker0` address (172.17.0.1) was not reachable from Desktop's containers. So `mcp.bind` matters for a native engine only.
- T-2160: an adapter asks for `FLAI_MCP_URL` and `FLAI_MCP_TOKEN` through `serve.MCPAsker`, which `serve` defines, so `harness.go` was left alone (S-0516 changed it at the same time). A `Capabilities` field could replace it later. S-0508's adapter implements it and maps the URL's host to the host gateway.
- T-2419: `HTTPLongestWait` is `HTTPPermissionHold`, one 45-second figure for every hold over HTTP (ADR-0244). I-0228 stays open for a `task_done` or `story_start` slower than 60 seconds.
- Under load, `TestServeSaysTheFlaiIsOlderThanTheProject` failed once and passed when run again alone (recorded as I-0252). `TestTheOperatorsStopIsOneStoppedAgentEvent` and `TestWaitForWorkPassesOverAHeldStory` did the same in a sub-agent's run.
