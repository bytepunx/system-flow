# S-002 Template prototype under ./template

## Context
The template is the executable form of the standard, designed in design/system/template.md and decided in ADR-0005. The prototype lives in ./template with a template.yaml manifest and a root/ tree. Files ending in .tmpl use Go text/template with variables from the manifest and `.layout.*` folder names. Nothing renders yet because flai does not exist; the files were written to be correct under the rendering rules in template.md.

## Current state
T-005, T-006, T-007 done. template/ contains template.yaml, README.md, and root/ with CLAUDE.md.tmpl, README.md.tmpl, system-flow.yaml.tmpl, devex files, and design, docs, wip skeletons. Fourth acceptance criterion (renders and passes flai check) is blocked on S-005 and is left unchecked. Story is in review.

## Next steps

## Decisions
- Template-repo-only files (its README) sit outside root/ so nothing needs an ignore list beyond the manifest default.
- Layout folder names appear in rendered files as `{{ .layout.design }}` so renamed folders stay consistent.
- Makefile targets call flai rather than reimplementing anything.
- projects/ sub-project skeletons deferred; manifest declares the kinds so the schema is settled.
