# S-0032 flaiover observability: request logs, health, metrics, traces

## Context
Applies design/conventions/logging.md and telemetry.md to flaiover (created by S-0030). The service side of the conventions: pino request and lifecycle logs on stdout, /_health and /_ready, /metrics with the golden signals and build_info, OpenTelemetry traces to a collector, and a local compose stack with a collector and viewer. Library choices were recorded in design/tech/observability.md: pino, the OpenTelemetry Node SDK, and a Prometheus client; prom-client turned out to be deprecated in favour of @prometheus-io/client, which declares Node 22, 24, or 26, so the Node 25 host installs it with the engine check relaxed while CI and the image use 24.

## Current state
Complete and verified on the served build. pino logging (JSON, `service`/`component`/`ts`/`level`/`msg`, request line with `trace_id` or `request_id`, lifecycle events for server start, watcher start, index build, watcher errors), `/_health`, `/_ready` with timed dependency checks, `/metrics` with the golden signals and `flaiover_build_info{version,commit}`, OTLP traces behind `OTEL_EXPORTER_OTLP_ENDPOINT` with W3C propagation, `flaiover/compose.yaml` with grafana/otel-lgtm, operator docs, tech pins, 38 unit tests. Story in review.

## Next steps

## Decisions
- Logger base carries `service: flaiover`; each module sets `component` (http, server, search, watcher) so the convention's `component` field is never duplicated.
- `flaiover_build_info.version` prefers `FLAIOVER_VERSION` (baked into the image from `git describe --match 'flaiover/v*'` by scripts/flaiover-image.sh and release-flaiover.yml), else the tag Vite compiles in at build time, else the package version.
- Requests without an active trace get a `request_id` (UUID) so every request line has a correlation ID, per design/conventions/logging.md.
- Health, ready, metrics, and `/_app/*` requests are not logged; they are still counted in metrics.
- prom-client is deprecated upstream; `@prometheus-io/client` is the successor and is pinned instead (I-010 records the Node 25 engine mismatch).
