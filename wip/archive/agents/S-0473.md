## Decisions

- I-0158 is a fault in the test, not in flai serve. `putEnded("Other")` and the message's time came from separate `time.Now()` calls, and `messages.ToSince` takes what is strictly after a run's start. When the second turned between them, the message was new to the other story's agent, and `look` started it, rightly by ADR-0154. So the fix is in the test alone: the waiting story's run, and so its message, is put a minute before the other run started, with `endedAgo`.
- The reproduction puts the other run a second earlier, as when the second turns. Before the fix it failed every time, at the line the issue names ("started before the reply", MS-0001); with the fix it passes.
- Plan: one task, T-1992, in one layer. It waits for nothing and runs alone. I worked it myself rather than through a sub-agent, because it is a two-line change to one file I had already read.
- I cancelled the planner's T-1986 and T-1989 (TH-0574) because they duplicate T-1992. T-1992 was written and done before their plan reached me. It also chose a different fix from T-1986: it moves the waiting story's run a minute earlier rather than pinning the other run to the message's second. With that, the message comes before the other run started, which `messaged` never looks at, so the S-0335 rule for the same second does not come into it.
