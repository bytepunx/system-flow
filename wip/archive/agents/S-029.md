# S-029 flai release computes the bump, tags, and pushes on acceptance

## Context
Acceptance has been a hand-run sequence (move done, archive, commit, tag, push) that the agent performs after the operator approves. The git convention says acceptance triggers the release automatically and defines the bump by delivery type with incidental touches as patches. This story encodes that in flai: a release package that computes the plan from the item, its commits, and the manifest's components, and an accept command that runs the whole acceptance step. A tag must sit on the acceptance commit, so acceptance and release are one command rather than a hook on move.

## Current state
All three tasks done, story in review. flai/internal/release computes the plan; `flai release <id>` shows or applies it; `flai accept <id>` runs the whole acceptance (done, archive, template bump, commit, tags, push) and refuses a dirty tree without --yes. system-flow.yaml lists flai (cli), flaiover (dashboard), and template (template, conventions) as components. Tests: unit on a synthetic git repo (delivered vs incidental, docs-only, ambiguity, parent tags, --deliver, template bump, epic major, numeric tag sort) and an end-to-end accept. Docs, design, and the git and work-management project additions describe acceptance through flai accept. Lint and all tiers green. Committed at review and pushed.

## Decisions
- Acceptance and release are one command rather than a hook on move: a tag must sit on the acceptance commit, which does not exist when move runs.
- Components are the manifest projects; the template is a component of kind template whose release is a version-file bump and changelog entry, not a tag (the template repository gets its tag from S-021).
- The delivered component comes from --deliver, then item tags, then parent tags, then the only touched component; two touched components with no tag is an error, never a guess.
- Versions come from existing tags with numeric ordering, so 0.10.0 sorts above 0.2.0.
- Dependabot merges are not items and stay hand-tagged for now; recorded in git.md.
