- Layer two: T-0794 (convention, design, docs, template release) waits for all of layer one, since it describes them; T-0795 (`planner.md`) waits for T-0791, since it says what the prompt says. Their paths do not meet.

- AC 3 is met by checking MCP `item_new` whenever a body is given, as the CLI's `--body-stdin` is, for every caller rather than the planner alone: an authored body is checked either way.
- T-0792 makes every MCP `item_new` with a body refuse a body missing a template section, as `--body-stdin` does; two tests with partial bodies were completed. A caller gets the missing section named and writes it again.
- AC 4: flai fills the run-end entry's items from what changed under the planned item since the run started (`created`, `updated`); the planner's summary names created and revisited stories in words. An operator's edit under the item during the run is counted too; accepted, since planner runs are short and on the operator's word.

- T-0796 no longer waits for T-0795: a planner run uses the main checkout's `planner.md` until S-0209 is accepted, so the copy does not change what the designer judges. Only the prompt comes from this branch's `flai plan`.

- Close-out stops at `flai check --strict` on overlaps with S-0255 and findings outside S-0209; S-0209 goes to review with the rest of the close-out passing, as S-0225 did, and I-0057 records it. Touches are not narrowed to clear the overlap.
