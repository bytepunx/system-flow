# S-0071 Research how the dashboard and a flai process on the host can talk, so that actions in the dashboard trigger actions on the host

## Context
Research, raised by the operator on 2026-09-20 after they found that a move to ready starts no work: how the dashboard (in its container) and a flai process on the host can talk, with flai opening the connection, so that actions in the dashboard trigger actions on the host. Output: a finding under `design/system`, the operator's decision as an ADR, follow-up stories under E-0003. Nothing is built. It must not reopen what ADR-0027 closed: the container gets no way to execute on the host except named actions flai implements.

Constraints on trials: scratch projects, scratch containers, throwaway tokens; never the operator's dashboard or credentials; stop processes by PID or container name (I-0025).
