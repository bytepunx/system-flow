# S-0167 Right click menu for the board

## Context

A context menu on each board lane: create an item starting in that lane, move stories forward (backlog) or back (ready, in-progress, review, cancelled), and change the lane's WIP limit. flai's rules allowed no backward move but review to in-progress, and had no command for the limits, so the story reaches into flai as well as flaiover (touches widened).

## Decisions

- The backward moves are a change to a rule flai enforces and to what `completed` means in the metrics contract, so they get an ADR (decisions.md, metrics.md).
- "Move stories" is read as a choice of stories in the lane: the menu opens a dialog listing the lane's stories to tick, and a right click on a card ticks that card first. It serves one story or all of them.
- The WIP limit is changed in `wip/kanban/board.md` only: flai, flai serve, `flai check`, and the dashboard all read it from there. The convention's project addition stops restating the numbers so nothing goes stale.
- Only ready, in-progress, and review carry a WIP limit (workflow.md), so the limit entry is offered on those lanes only.
- Creating into ready or in-progress creates in backlog and then moves the item along with the ordinary moves, so every rule of those transitions still applies; a refusal is shown and nothing is undone.
