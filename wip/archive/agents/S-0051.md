# S-0051 Accepting from the dashboard shows uncommitted changes outside wip and lets the designer include them

## Context
Accepting from the dashboard is refused after the confirmation when the working tree has uncommitted changes outside `wip/`, with advice to pass `--yes`, which the dashboard cannot do (I-0019). The preview hides it because it runs `flai accept --dry-run --yes`. The operator asked for the choice as a prompt. The check is `dirtyOutsideWip` in `flai/cmd/branch.go`, used in `acceptItem` in `flai/cmd/accept.go`; `--yes` is a global flag, so `flai move <id> done --yes` already includes the files. The dashboard side is `flaiover/src/routes/api/items/[id]/acceptance/+server.ts`, `.../move/+server.ts`, and `src/lib/components/AcceptConfirm.svelte`. The container also lacks the host's global gitignore, which is how an ignored file became "uncommitted" there. Work is in `.flai-cache/worktrees/S-0051` on `story/S-0051`.

- 2026-09-18, agent: the endpoint helper is `_moveArgs`; SvelteKit rejects exports from `+server.ts` that are not handlers or underscore-prefixed.
