## Decisions

- The computations go in a new package, `flai/internal/planning` (forecast, cost of delay, co-change scoring), apart from `metrics`, which is the `flai stats` contract; git reading stays in `storygit` (`CommitFiles`). The story's touches were widened with `flai/internal/planning` and the convention files.
- The three commands only print. Writing stays with `flai edit` and `item_edit`, which stamp `by` and `at` (ADR-0074), so the planner reviews a figure before it is written.
- Plan, three layers:
  - Layer 1: T-0815 (touches suggest) and T-0816 (forecast, `planning.default_duration`). No path in common, but both build `flai/cmd` and T-0815's scoring sits in the package T-0816 creates, so each runs in its own task worktree from `story/S-0210` and I apply each diff to the story's worktree.
  - Layer 2: T-0817 (cod) waits for T-0816, whose `planning.Forecast` it apportions by and whose `root.go` registration it extends. T-0818 (guard, prompt, planner.md, convention, template) waits for T-0815 and T-0816, whose commands and flags it names. They share no path and run together.
  - Layer 3: T-0819 (design and user docs, generated reference) waits for T-0817 and T-0818, since it describes what they settle.
- Layer 1's sub-agents both worked in task worktrees; I applied their diffs to the story worktree, renamed a test fixture both had called `history` in package `planning`, made `planning.Forecast` take a short ID (`S-10`), and regenerated the reference with each commit rather than leaving `TestReferenceIsCurrent` red until T-0819.
- T-0819 no longer waits for T-0818 (`flai edit T-0819 --after T-0817`): what is left of T-0818 is the operator pasting the planner's definition (TH-0109), which the docs do not depend on.
- The template bump is a patch, 1.0.45, as every template entry before it, since the story delivers to `flai` and touches the template incidentally (git.md).
- T-0819's sub-agent found `flai guard`'s help still listing the old reads; I added `cod`, `forecast`, and `touches suggest` to it and regenerated the reference.
- The sync named the issue files the bumps changed as outside the touches; the story's touches now list them.
- Layer 2's tasks share the story worktree: T-0817 builds `planning` and `cmd`, T-0818 `guard` and `harness`, which import neither.
