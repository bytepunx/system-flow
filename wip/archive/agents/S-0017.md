## Decisions
- The reference is its own page, `docs/users/flai-reference.md`, linked from `flai.md`: about 2,000 generated lines would bury the guide, and a separate file lets the generator own the whole file. `flai.md` stays the hand-written guide and documents the config file.
- A hidden `flai reference` command renders the page with the standard library, not `cobra/doc`: no new dependency (code-quality.md), and the output is shaped for this repo's markdown lint and anchors.
- `--write` rewrites the file only when the body changed, so `updated` moves only then and the staleness test compares bodies, not dates.
- `docs/users/flai.md` goes from `status: draft` to `active`: it was a draft for want of the generated reference, which this story adds.
- One commit per task, as the operator's start instruction for this session says, where `git.md` says commit when the story lands; the operator's instruction takes precedence.
