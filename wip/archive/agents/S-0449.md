## Decisions

- Plan, layer 1: T-1904 (harness: margin, measurement, nothing of a prior component) and T-1905 (the page's frame: stale answers, pane). They share no path, so they run together.
- Plan, layer 2: T-1906 (a framed component's requests, and the headless pass for 500s). It waits for T-1904, since both change `harness.mjs`, `integration_test.go`, `component-library.md`, and `docs/users/flai.md`. It waits for T-1905, since both change `docs/users/flaiover.md` and its pass checks both.
- Criterion 3's task is written once TH-0515 is answered: how far the skeleton goes decides whether `props.mjs` gains type resolution.
- The 500s are a framed component's own `/api` fetches, answered by flaiover's dev server without a token (component-library.md § What the pass found). The dashboard's log since its last start shows no 5xx from the Components page's own routes. So the harness answers those requests with 501 and logs each as an event, rather than the page's routes changing.
- Tagged `flaiover`, then `flai`: the screen is the delivery, and the harness in flai changes with it.
- T-1904: the measurement leaves out the box of any fixed element pinned to the viewport's top and bottom, a drawer included, but counts what it holds. Otherwise a frame-tall element grows the frame by the margin on every measure.
- T-1905: the frame's wrapper no longer clips or rounds, so the frame's own scroll bars show whole.
- TH-0515, confirmed by the operator on 2026-10-19: option (A). flai resolves each json prop's type with the sub-project's own `typescript`, imports and `$lib` aliases included. The catalogue carries an empty skeleton, with one element for an array. The props panel fills the field with it and sends it. Where a type cannot be resolved, the skeleton falls back to `[]`, `{}`, or `null`. A literal default still wins, and Reset returns a field to its skeleton. Both rule changes are recorded in `component-library.md`.
- Plan, layer 3: T-1907 (flai: a skeleton in the catalogue) and T-1908 (flaiover: the panel fills the field and sends it). They share no path, and they agree on one contract: `skeleton` is a JSON value on the prop, set for array, object, and unknown props only. So they run together. T-1907 owns `component-library.md`, so both rule changes are written there.
- T-1906: the harness answers a framed component's fetch to the app's own server with 501, and fails its EventSource without a connection, posting each as an event (ADR-0172). XMLHttpRequest, sendBeacon, and WebSocket are left alone, since no flaiover component uses them.
