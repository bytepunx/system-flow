## Decisions

- Use a fixed table layout instead of the auto layout. With auto layout and percentage widths, the spare width still went to Process when the actions were hidden (255px).
- Widen both host-page cards to `max-w-3xl`. At `max-w-2xl` the three columns would get about 107px each with the actions shown. `HostPanel` widens too so the two cards stay aligned. Nothing else renders `HostPanel`.
- Let the MCP project list break inside long names (`break-words`). A fixed layout would otherwise let a long name overflow the 7rem column.
- Use the `Co-Authored-By: Claude Opus 5.5` trailer, which names the model that wrote the change. The operator confirmed this rule in TH-0009, and T-0396 wrote it into `design/conventions/git.md`.
- Record the dev script's stale token path as I-0039, not as an open question here. It is outside this story's scope.
- Act on TH-0009 as T-0396 on this story. S-0112's agent opened it and S-0112 is archived, but the answer settled this story's own trailer decision, and the edit is one line.
