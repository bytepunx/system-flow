- The fallback is wider than the planning note's `{}` config. The scratch `config.json` keeps the original's `currentContext`, and the scratch folder links every other entry of the original folder: `cli-plugins`, `contexts`, `buildx`, and the rest. - Only the build paths fall back: the default build and `--layer`. `--tag` and `--check` pull nothing.
- The test does not cover a helper that hangs: it would add ten seconds to every smoke run. A hang reaches the same path as an exit 1, since `timeout` exits 124.
