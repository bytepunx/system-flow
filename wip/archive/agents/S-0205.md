## Decisions

- Plan: one task per layer, in order T-0777, T-0778, T-0779, T-0780, T-0781, T-0782, T-0783. T-0777 writes the contract the others implement. T-0778 to T-0782 each add a section to `flai/internal/metrics` and all change `metrics.go` (the `Report`, `Options`, and `Compute` wiring), so each waits for the one before. Nothing runs in parallel. T-0783 wires `flai stats` and prints the aggregates, so it waits for all of them.
- Errors are keyed with their unit (`forecast_error_seconds`, `delivery_error_seconds`, `estimate_error_seconds`), as every duration in `flai stats --json` is. The existing relative `estimate_error` stays, so nothing the dashboard reads changes. ADR-0081.
- Holds are not recorded anywhere: `workitem.Holds` computes them live. So held time is replayed from the hold rules at each transition, with today's touches and `after`. The criterion says "where recorded"; replay is the only source there is. ADR-0081.
- Cost of delay incurred = value per week × seconds in backlog or ready / 604800, at today's value, since flai keeps no older values.
- A thread's wait runs from its first entry to the first later entry by another author. The union of overlapping waits counts once, clipped to the story's in-progress intervals. Review wait is the time in review.
- Touches drift reads git in `flai stats` through a new reader in `flai/internal/storygit`. Commits whose subject has `[S-nnnn]`, merges and `wip/` left out. The metrics package stays free of I/O and takes the committed files in `Options`.
- The dashboard reads stats through hostapi `stats.compute`, which calls `metrics.Compute` as `flai stats` does. T-0783 gives both one reader, a new `flai/internal/statsread`, so they pass the same inputs. T-0783's touches and the story's grew to cover it.
- Held time is replayed at each creation as well as each transition of a story or task. A task's creation changes its story's claim. `metrics.md` says so.
- The new sections cover the report's type, like the existing aggregates. Epics get their own cost of delay with `--type epic`, and stories' shares of an epic's value are never added to it.

- Went to review with `flai check --strict` failing only on findings outside the story that main reports too: S-0173, E-0015, and TH-0094. The designer ruled on TH-0056 that findings outside a story are notes, and S-0206 did the same. I-0057 is bumped.
