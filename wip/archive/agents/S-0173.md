## Decisions
- 2026-10-01: a thread with no item and no item file or narrative leads to a new /threads page, opened on it, listed under Workflow (TH-0041, alex). Added as T-0613.
- The answer form for an open question is one component, used by the inbox and the story page, so the two cannot drift.
- A thread with no item but whose path is a work item's file or a narrative, live or archived, leads to that item's page: the item is read from the path.
- The Threads page starts no new thread, because a thread needs an anchor; each thread on it links to its anchor, which may be a document page. Only the inbox's own links are kept off documents.
- 2026-10-01: T-0614 added. `flai check` rejected the in-progress to ready move that ADR-0055 allows and that flai made when it restarted S-0173, so `check --strict` failed on main. That is a small fix, so it is a task on this story (work-management.md). check now uses `workitem.Follows`.
