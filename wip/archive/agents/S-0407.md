## Decisions

- **Plan kept as the planner drafted it.** Layers: 1. T-1690 (the reader defines the plugin's input and answer); 2. T-1691 and T-1692, which share no path (the plugin speaks T-1690's protocol; the capability rests on T-1690's reader existing); 3. T-1693, the integration test, which needs both the plugin and the capability; 4. T-1694, the docs, which describe what the test shows.
- **Sub-agent sign.** S-0406 found a plugin tells a sub-agent's call by its `sessionID`: the Task tool runs it in a child session whose `parentID` is the caller's (`agent-adapters.md` § Read from the source at v1.19.5, finding 1). The plugin looks each session up with `client.session.get` and sends its `parentID` and `agent` with the call, so `Guard: true` holds and criterion 3 takes its first branch.
- **Protocol.** The plugin sends `flai guard --harness opencode` one JSON object on standard input: `event` (`tool.execute.before`, `session.created`, or `tool.execute.after`), `tool`, `sessionID`, `callID`, `args`, and `session` (`id`, `parentID`, `agent`). The guard answers as for Claude Code: exit 2 and the reason on standard error refuses, any other exit passes. An Ask passes, as Claude Code's does: OpenCode's own permission rules, the deny rules ADR-0260 gives it, decide; hold-and-ask is S-0408's.
- **`apply_patch` may write several files.** The reader decides on each path the patch names, the first refusal winning, so one protected file in a patch refuses the whole call.
- **flai missing.** The plugin passes every call when `flai` is not on `PATH`, warning once (criterion 2), except in a session flai started (`FLAI_STARTED_BY`, `FLAI_STORY`, or `FLAI_ROLE` set), where it refuses as ADR-0235 has the Claude Code hook refuse: there a missing guard means an unguarded agent.
- **The plugin files are written by the story's agent.** `.opencode/` is protected on every harness (D-0514), so a sub-agent's write is refused; the story becomes operator-accepted under ADR-0106.
- **This repository's plugin runs the tree's flai.** `.opencode/plugins/flai-guard.js` here differs from the template's in one constant: it runs `scripts/flai.sh`, as `.claude/settings.json` runs the guard, so the guard on this branch is the tree's (delegation.md project additions).
- **Start refuses roles without the plugin** (T-1692): `Guard: true` is true only where the project has the plugin, so a story whose agent names roles in a project without `.opencode/plugins/flai-guard.js` is refused at start, naming `flai upgrade`.
- **MS-0348 with S-0410.** Both stories change the opencode adapter's `Capabilities` line. Agreed split: whichever is accepted second resolves to `{Resume: true, Guard: true, Cost: true}`.
- **Integration test on the real binary.** opencode is not installed on this host; T-1693 installs opencode-ai 1.19.5 into a scratch folder under `.flai-cache/` (git-ignored) to run against, and the test skips, saying so, when `opencode` at that version is not on `PATH`.
