## Decisions

- Tasks are committed one by one, as the start instruction says, not only when the story lands as `git.md` has it.
- Avg. Time / Model plots agent minutes per item, the mean usage `seconds` of the items each model worked on, not cycle time (designer, TH-0040, 1a).
- Avg. Cost / Model is its own chart, and Tokens per item and $ / Work Type lose their compare control, always one line per item type (designer, TH-0040, 2a).
- "Tokens per item" keeps its title: the story does not list it.
- A bucket-named title follows the bucket chosen: Tokens / Hour, $ / Week.
- flai's spend gains `minutes_per_item` so that flai stays the reference for the numbers the dashboard draws; the dashboard works it out from `seconds` when an older flai sends none.
- `flai stats --json` keeps `aging`, estimates, `usage.done`, and `usage.by_model` for scripts, though no chart draws them now (ADR-0057).
- Recorded in ADR-0057, refining ADR-0053, since metrics.md defines the charts.
