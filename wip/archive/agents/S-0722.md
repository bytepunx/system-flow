GOMAXPROCS=1 with -parallel 4 took 20.2 s at a mean of 1.02 and peaks of 2.9 and 1.3; not taken, since the story asks for one core and the tests that start git would push past it.
- The go-test tier runs env GOMAXPROCS=1 go test, since a tier has no env key. manifest.tests-timeout's check (manifest_tests.go goTestFlags) now sees go test through a leading env and the variables it sets, so the tier keeps that guard; TestTestWarnings holds it.
