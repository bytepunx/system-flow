## Decisions

- Kept the planner's five tasks, touches, and `after` (TH-0666). Layers: 1 is T-2155 (adapter), T-2156 (host settings), and T-2157 (protected list), which share no path and wait for nothing, run together; 2 is T-2162 (serve start, refusals, stop, restart), which waits for T-2155's `Start` argv and `Stdin` and T-2156's settings; 3 is T-2169 (documents, live run), which waits for T-2162 and T-2157, whose behaviour it documents.
- T-2162 gains the image's Claude Code version step and `serve/claudecheck.go` in its touches, as TH-0666 settled it (the orchestrator's recommendation, confirmed by flai serve): read `claude --version` from the image, record it, and warn when no passed check covers it; the headless check inside the image goes to an issue.
- Criterion 6's live run needs the adapter in the installed `flai serve`, so it cannot run before S-0508 is accepted and published; asked on TH-0812 whether to move it to a follow-up story, as D-0461 records for S-0423.
- T-2157's root-relative entries (`flai/images/`, the two scripts) did not match the guard's sub-agent check, which passed the hook's absolute path; `protectedWrite` in `flai/internal/guard/call.go` now reads a write's path from the story's worktree too, committed with T-2157.
- `flai serve settings` shows the container's images, network, and login in its text view too (`flai/cmd/serve_settings.go`, with T-2156).
- flai serve opens a story's worktree before a container start when it has none (T-2162), rather than refuse: docker would make an empty root-owned folder at a missing mount, and serve does not open worktrees for claude-code, whose agent's `story_start` does.
- The flai-cli.md conflict with S-0553 (MS-0303) is S-0508's to resolve at its next sync after S-0553 lands; replied settled.
- Limitations filed: I-0253 (the image's Claude Code is not checked against permission_prompt) and I-0254 (a native Linux engine and the 127.0.0.1 bind). Git in the container and the close-out in the image are S-0517's and S-0520's already.
- TH-0812 answered yes (the operator confirmed the orchestrator's recommendation, 2026-11-02T18:08Z, as D-0461): criterion 6 moved to S-0565, a draft experiment in E-0029 with `after: S-0508`, which holds its words and T-2169's live-run Work. T-2169 was already closed on the documents and a done task takes no edit, so its title still names the live run; S-0508's Notes say so.
