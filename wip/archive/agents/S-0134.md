## Decisions

- Tasks are committed as they finish, as the flai-serve prompt asks, rather than only at review as `git.md` says; the operator's instruction wins.
- Topics live in a new package, `flai/internal/topics`, rather than in `conventions`, because design, tech, and ADR files use them too; added to the story's touches.
- Criterion 2 is read as: `flai doc save` accepts a save of an accepted ADR whose only change is its `topics` key, and refuses every other change. The dashboard editor keeps showing an accepted ADR read-only (mode `none`), so it refuses every change; the reason it gives names `flai adr topics`.
- The template's version and changelog are not bumped by hand: the release tooling writes them at publish (`git.md`), and a hand bump would count twice.
- `topics` goes at the end of an ADR's front matter when it is not there yet, and replaces the key in place when it is; a topic must be a word (letters, digits, `.`, `-`, `_`).
- Design and tech topics chosen here: product-wide documents `[all]`; the rest by the sub-project words they concern (`cli`, `dashboard`, `template`, `conventions`, `go`, `sveltekit`, `code`). The designer may narrow or change them.
- The six markdown lint errors main carried in wip (S-0122 and S-0124 archives, TH-0012) were fixed in one `chore` commit on main (88e345f), under the designer's answer A on TH-0017, because they failed this story's smoke tier; I-0027 bumped to 4.
- Criterion 3's vocabulary includes stories' and epics' topics, but items have no `topics` key until S-0135 (items parse strictly, so none can carry one); the check's vocabulary is the manifest's words, `code`, and `all` until S-0135 adds the items'.
- TH-0028 answered C: `flai upgrade` keeps a project's own `topics` on a convention, fixed in this story (T-0494), with a criterion added for it. The lock records the template's topics per marker file, so a project's topics count as its own only when they differ from what the template last gave it; with nothing recorded they are kept. Recording them in the lock refines ADR-0015 (an added field), a living-design edit rather than a new ADR. Heading comments above the marker stay the template's.
