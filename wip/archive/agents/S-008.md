# S-008 flai check and flai stats

## Context
flai check is the reference validator for the standard and flai stats the reference implementation of design/system/metrics.md; the dashboard is fixture-tested against both. Rules come from work-hierarchy.md, workflow.md, agent-narrative.md, and documentation-standard.md. workitem.Item.Validate already covers single-item rules; check adds cross-item, narrative, board, and documentation rules with file and line. This repo is the first thing check runs on, so anything it finds in wip/, design/, or docs/ gets fixed in this story. S-008 was pulled and its tasks created with flai itself.
