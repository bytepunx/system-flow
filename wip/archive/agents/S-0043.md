# S-0043 MCP over HTTP and project identity in the API, hub-ready

## Context
Last story of E-0006. Remote agents and a future multi-project hub should reach the same MCP server through flaiover over HTTP with the bearer token, and every API response should say which project it is from. `flai mcp` is a stdio server built on the official Go SDK (`flai/internal/mcpserver`); flaiover authenticates with one project token, bearer or cookie (`src/lib/server/auth.ts`, ADR-0018), and wraps most JSON responses in `respond()` (`src/lib/server/respond.ts`); a few endpoints stream or build their own response (events, accept, login, logout). The manifest has `name` and `key`; the template always renders a key. The Go SDK already has a Streamable HTTP client, so an official client can test `/mcp` without a new dependency. Work is in `.flai-cache/worktrees/S-0043` on `story/S-0043`.

## Decisions
- 2026-09-19, operator: pull S-0043 next.
- 2026-09-19, agent: `/mcp` is a bridge in flaiover's server between Streamable HTTP and one `flai mcp` stdio process per session, as the criterion asks; the rules stay in flai (ADR-0016).
- 2026-09-19, agent: responses from `/mcp` are plain JSON and the GET stream is not offered (405, which the specification allows); `flai mcp` sends nothing unprompted that a client needs.
- 2026-09-19, agent: project identity is a `project` member in JSON object bodies and two headers on every response. Array responses (`/api/items`, `/api/threads`, `/api/docs/tree`, `/api/docs/adrs`) keep their shape and carry the identity in the headers only; wrapping them would break the API for its one consumer and is better done with the hub, if at all.
- 2026-09-19, agent: the official client for the transport test is the Go SDK flai already depends on, not a new JavaScript dependency.

- 2026-09-19, agent: refusals (401, 403) carry no project identity, so an unauthenticated caller learns nothing about what is served.
- 2026-09-19, agent: the cookie never opens `/mcp`, even with the CSRF header, and an `Origin` that is not this host, `null` included, is refused.
- 2026-09-19, agent: the session's agent name is made safe for a file name, because flai keeps a cursor per agent under `.flai-cache/mcp/`.

## Open questions
- The criterion says every `/api/*` response carries `project: { name, key }`. Array responses carry it in headers only (see Decisions). Should they become objects (`{ project, items: [...] }`) before a hub exists? Proposed: no, decide with the hub story; the headers already let a front end route and label.
