# S-001 Define the standard

## Context
The root CLAUDE.md is the brief for system-flow. This story turns it into a settled standard: living design in design/system, decisions in design/adrs, technology in design/tech. The repo was empty apart from CLAUDE.md and is not yet a git repository. Everything in this story was written in one session on 2026-09-15 without tooling, so front matter was written by hand and has not been validated by flai check, which does not exist yet.

## Current state
All four tasks are done. design/system has twelve documents, design/adrs has twelve accepted ADRs plus a template, design/tech has eleven files. wip/ is bootstrapped with four epics, nineteen stories, and seven tasks. Story is in review awaiting the human's acceptance of the decisions.

## Next steps
1. Human reviews the ADRs and design/system; any reversal becomes a new ADR.
2. On acceptance, move S-001 to done and archive.
3. Root CLAUDE.md still holds the original brief; decide whether to replace it with the rendered template baseline plus the brief moved to design/system/brief.md. Open question below.

## Decisions
- Blocked is a flag, not a column, so time in state stays honest. ADR-0004.
- Kanban items are flat per type with `parent` keys, archived on completion. ADR-0012.
- Metrics have a Go reference implementation and the dashboard is fixture-tested against it. ADR-0006, ADR-0007.
- No sprints. Weekly chart review is the improvement loop. workflow.md.
- Sub-projects sit at the repo root; their design lives in design/system/<project>.md. ADR-0002.
- Tech versions pinned to what is on the dev host: Go 1.26, Docker 29; Node 24 LTS chosen over the host's 25 for the image.
