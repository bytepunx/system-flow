## Decisions

- Reviewed the planner's three tasks (approved on TH-1154) and kept them as written. Layer 1: T-3291, the rule in undone.go and its unit tests. Layer 2: T-3292 (real-git reproduction in sync_test.go) and T-3293 (ADR, design, user guide, close I-0360), each after T-3291 because they test and describe its rule; they share no path, so they run together.
- T-3291 worked by the story's agent itself, not a sub-agent: it had already read undone.go, and the change is two call sites and two small functions.
- Kept-words rule: in a path whose extension is .md (any case), each of main's lines the branch removes is kept when a line the branch adds holds its words, split on white space, as a subsequence; each added line keeps one of main's at most, the first unused one in order (a greedy match, not an optimal one). A line of main's with no words, such as a blank line, is never kept by the rule, so ADR-0155's whole-line check stays the only check for it.
- RecordedUndone applies the same rule, so a record written before the fix, such as S-0761's, drops a path whose branch line now keeps main's words.
- Changed T-3291's rule from words in order (a subsequence) to a multiset of words, split on white space with the punctuation at each word's ends trimmed (unicode.IsPunct), in any order. Why: T-3293's sub-agent found, and I checked against .flai-cache/undone/S-0761.json and d3816140e, that S-0761's resolved row moved one 'and' of main's and turned 'ADR-0256),' into 'ADR-0256,'; only 3,555 of main's 3,970 words were in order, while the trimmed multiset holds every one. The in-order rule would not have cleared I-0360's own instance, so criterion 1 needs the multiset. This departs from the plan approved on TH-1154, which said in order; recorded here and in ADR-0297's Alternatives.
- Added a revert guard with the multiset rule: a line the branch adds that is one of the lines main removed since the old base keeps nothing, so a replayed revert of a change that only took words out of a line is still caught (gap found by T-3293's sub-agent). RecordedUndone reads main's removed lines with one more git diff from the recorded old base, only for a markdown path whose branch adds a line.
- ADR-0297 is amended in place, title included, since it is this story's own and not yet on main (D-0591). Its file name keeps the slug flai adr new gave, which the new title still begins with.
- T-3292's sub-agent put the reproduction in notes/table.md, outside design/ and docs/, so no section merge settles the stop and the resumed sync (ADR-0294) runs the undone check, as it did for S-0761.
