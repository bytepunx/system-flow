## Decisions

- Kept the planner's three tasks in three layers (TH-0342): T-1297 (code and test) first; T-1298 (docs) after it, since the docs describe what the code does; T-1299 (close I-0095) after both. No two share a path; each layer is one task, so none ran together.
- Took I-0095's first direction: `askedAnswered` judges a run `asked` when its agent wrote on a thread of its story after the run started and that question has an answer. Recording the wait at ask time from the MCP server was not taken: it needs new run state.
- An entry in the second the run started does not count (T-1297's sub-agent): times are kept to the second, and the run started again for an answer can start in the second the question was asked, which would judge it asked again on the same answer.
- An answer that came while the run was still going counts too: an agent that asked, read the answer, and then ended without finishing is started again once, spending no automatic restart. Counting only answers after the end would miss the gap between the agent being told to end and its process exiting.
