## Decisions

- Role names: the verbs `plan`, `orchestrate`, `analyze`, as the story says, replacing the nouns S-0196 put in `conventions.Roles`; no file used them. They match `explore`, `verify`, and the host actions S-0208, S-0218, and S-0223 name. Stated on TH-0081.
- Plan, layer 1: T-0746 (flai code: conventions, context, prime, MCP) and T-0747 (convention files here and in the template) wait for nothing and share no path, so they run together; T-0747 only needs TH-0081's answer, and its new roles are only `flai check` warnings until T-0746 lands. Layer 2: T-0751 (design, ADR, user guide) waits for both, because it describes the flags and roles they settle.
- A strategic pack's topics are its role's topic (`planning`, `orchestration`, `analysis`, which E-0016 declares), plus, for the planner, its item's topics. The README is left out of the strategic packs, as of the sub-agents', because its "read every file below" is the story's agent's.
- TH-0081, 2026-10-03: the designer chose the recommended roles. work-management `[story, plan, orchestrate]`, decisions `[story, orchestrate]`, continuous-improvement `[story, analyze]`, code-quality `[story, verify, analyze]`, telemetry `[story, explore, verify, analyze]`, and strategic-agents `[plan, orchestrate, analyze]`.
- T-0746 review: a planner's pack for an epic names what the epic names, not what its stories name. The sub-agent's first version included the stories, and on E-0016 that pack was 131KB, past what a tool result carries; with the epic alone it is 84KB, and the planner reads the stories as items. `ForStrategic` takes the epic and the story apart, and refuses an ID whose type is not its flag's (`--epic S-nnnn`). The orchestrator and the analyzer get the story pack's design steps with no item, so they get a catalog as well as briefs. The role topic's source kind is `role`, defined in `context` (`FromRole`) because `internal/topics` was outside the task.
- T-0751 review: ADR-0075 said `work-hierarchy.md` and `workflow.md` gained the topics `planning` and `orchestration`. The sub-agent rightly left them alone, because `all` already selects them for every pack, so I corrected the consequence. Only `metrics.md` gained a topic, `analysis`. The sub-agent could not set ADR-0075's topics, which the guard refused it, so I set them.
- Close-out: no second verifier ran. The first found nothing to fix in S-0207's changes, and the only commit since is the I-0057 bump.
- `docs/operators/settings.md` is generated with `flai-reference.md` (`scripts/flai-reference.sh`) and changed with the new `--epic` flag. It was outside S-0207's touches, which I widened.
