# S-0142 Add a stream window to the activity page agent panes

## Context

flai serve starts each story's agent with its output in a log beside its state (`~/.flai/serve/agents/<key>-<story>-<time>.log`); Claude Code writes `stream-json` there. Nothing read it. The activity page showed narratives only. S-0142 makes flai read the log (`serve.Stream`), offer it over the channel (`agent.stream`) and as `flai serve agent stream`, and the activity page's cards show it live.

## Decisions

- The stream is read from the log flai serve already writes; nothing new is stored. One read is bounded (1 MiB consumed, 200 entries, 2000/400/300 characters per text/result/tool entry) and a first read takes the last 256 KiB. Reason: a session's log reaches megabytes, and a tool result can be a whole file.
- Heartbeats, token counts, rate-limit events, and empty (redacted) thinking are left out: they say nothing a reader follows.
- `agent.stream` is read-only and not gated by a host action, like `agent.status`: the dashboard is authenticated, and it already reads every document in the project. Tool results are cut to 400 characters, which limits what a file an agent read can show.
