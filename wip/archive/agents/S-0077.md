# S-0077 flai dashboard no longer mounts the clone, and everything that existed to make the mount safe goes with it

## Context
The last step of ADR-0029's move off the mount: reads (S-0073, S-0074), writes (S-0075), and MCP (S-0076) no longer need the project in the container, so `flai dashboard` stops giving it. Pulled while S-0076 is in review; the branch is stacked on `story/S-0076` (`git merge --ff-only`), so accept S-0076 first.

## Current state

## Decisions
- 2026-09-20: the container still runs as the host user. The two secrets are 0600 files of that user; the alternatives are environment variables, which ADR-0018 rules out, or world-readable secrets. It costs nothing now that nothing of the host is within reach. Recorded in ADR-0031.
- 2026-09-20: retired settings are accepted and explained, not rejected: an unknown flag or key would fail an operator's start on upgrade with no explanation. The config keys stay settable so they can be cleared.
- 2026-09-20: the clone audit (hooks and executing git settings already present) goes with the guard. It existed because the container could write them; it cannot any more.
- 2026-09-20: `worktrees.relative_paths` stays as ADR-0022 made it, though the dashboard has no use for it; ADR-0031 says so rather than removing a user's setting.
- 2026-09-20: the 404 mapping matches workitem's wording with a regular expression, because the write runs as a process and only its words and exit code come back. A dedicated exit code would be cleaner and changes the CLI's contract; the test takes the wording from `Repo.Get` itself so a change fails there.
- 2026-09-20: "tried with the published image" was done with 0.22.0, which still carries `PROJECT_DIR=/project` as an image default naming a directory that does not exist; the branch image, which drops it, was run as well.

## Open questions
- 2026-09-20: rootless Docker and user-namespace remapping are untried; if an operator uses either, the secrets may be unreadable in the container and the dashboard would say the token is missing. Worth a line in the operators' page once someone has such a host to try it on.
