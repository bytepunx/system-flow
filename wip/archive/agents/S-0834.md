- Corrected the planner's assumption 1: the worktree is mounted at its host path (`flai/internal/harness/container.go`, Start), so `exec` keeps its directory. Only the kluster config read and the copy are needed.
- The container already gets `--add-host host.docker.internal:host-gateway` (`dockerUser`). So T-3548 adds only `FLAI_KLUSTER_API_HOST`, set off the `host` network, and no new host name.
- The copy's kubeconfig puts its certificate authority inline, because the original may name a CA file under `.flai-cache/kluster`, which is not mounted.
- 2026-11-18: 2026-11-17: TH-1290: does the operator accept ADR-0319 as written, before T-3547 to T-3550 build it? — yes (answered by alex)
- T-3547's copy skips a file whose size and modification time match its source's. Before this, every record write rewrote every log, which the sub-agent named as a performance cliff.
- T-3548 gives FLAI_KLUSTER_API_HOST to the story's agent container only. The close-out's and checks' containers do not mount the cache folder, and strategic roles have no namespace.
- T-3549 added kluster.NewOr rather than changing New's signature, which S-0840 relies on (MS-0623). It also changed log.go, outside its touches, for ReadLogIn; task_done widened the touches.
