# S-0178 The activity stream page should not scroll to the top of the page when viewing an active agent stream

## Context

The operator watches an agent's stream on `/activity` and the page keeps jumping up, and the stream window jumps back to its end after they scrolled away. A sub-agent reproduced it in headless Chromium against the page with every `/api/*` mocked (copy under `/tmp/s0178-repro`, nothing in the repository touched). The main cause: `AgentStream.svelte`'s effect tracks the `story` and `started` prop getters, which the page rebuilds from new objects on every `/api/activity` load and every `/api/host-agent` read (every 15 s while an agent runs, and on every change event). Each re-run empties every box and re-reads the tail, so the page shortens (window 1555 → 793, or to 0 when the emptied page fits the viewport) and each box is put back at its end. A `$derived` of `started` and `untrack` around the first step held the window still (0 px moved) and left a box scrolled up where it was. Also moving the page: a failed `/api/activity` replaces the list with an error (window to 0, and it stays there); `/api/host-agent` answering `{enabled:false}` with no `state` while flai is away unmounts every box; `open={live(a)}` closes a stream when its agent ends; an empty `/api/projects` list drops the chosen project and the layout's `{#key}` remounts the page.

## Decisions

Layer 1 is T-0704 (`AgentStream.svelte` and its test), T-0705 (`routes/activity`), and T-0706 (`lib/project.svelte.ts` and its test): no path in common and nothing between them, so they run together, one task sub-agent each in the story's worktree, since none builds what another changes beyond the component T-0705 renders through `ActivityView` unchanged. Layer 2 is T-0707, the documents, after all three because it describes what they settle.
- A stream window now opens when its agent starts and never closes by itself (T-0704), where S-0142 closed it when the agent ended: the close shortens the page under the reader, which criterion 1 rules out. Closing is the reader's.
- The three page-structure causes (T-0705, T-0706) are in this story although they are not the stream's own effect: each moves the page while the operator watches a stream, which is what the story is about.
