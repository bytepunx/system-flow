# S-0049 A story is ready without tasks; the agent that pulls it writes them

## Context
The operator was refused `flai move S-0048 ready` because the story had no tasks. They want a story to be ready on goal and criteria alone, and the agent that pulls it to write the tasks after moving it to in-progress. The rule lives in `flai/internal/workitem/rules.go` (the `Ready` case), `flai/internal/check/check.go` (`story.tasks`), `design/system/workflow.md`, `work-hierarchy.md`, `overview.md`, the `work-management.md` baseline in the template and here, and `docs/users/flai.md`. Code, design, template, and docs edits are made in the worktree `.flai-cache/worktrees/S-0049` on `story/S-0049`; `wip/` is written in the main checkout.
