# S-0282 Story's should correctly tick acceptance criteria when they have verified them

## Context

Agents tick a story's acceptance criteria by hand-editing its file, or not at all. S-0282 gives flai one way to tick them, the same from the CLI (`flai criteria`), the dashboard's HTTP API (`item.criteria`, `POST /api/items/[id]/criteria`), and MCP (`criteria_tick`), and says in the conventions and flai serve's prompt that a criterion is ticked through flai once verified.

## Decisions

- Criteria are addressed by number, 1-based, in the order of the checkboxes in `## Acceptance criteria`; an optional hash guards against a change made meanwhile, as `flai edit` does. Numbers are what `flai criteria list` prints.
- The CLI is subcommands, `flai criteria list|tick|untick`, so that the guard lets a sub-agent run `list` as a read and refuses `tick` and `untick` by subcommand, as it does `flai thread list` and `flai thread reply`.
- Ticking goes through `itemedit.Apply` with the new body: the same checks, notice to agents (`changed: criteria`), and commit options as `flai edit`.
- A move to review with an unticked criterion warns and is not refused: work-management.md keeps a criterion that could not be verified unticked, with the reason in the story's notes.
- TH-0162, operator (alex, 2026-10-06T04:39:19Z): the story's agent ticks. A task sub-agent names in its final message the criteria its task meets; the story's agent reviews, then ticks each it verified. The guard keeps refusing sub-agents' writes; `flai criteria list` stays a read they may run.
- Plan, in four layers:
  - Layer 1: T-0991 (itemedit's criteria module) and T-0992 (review warning) wait for nothing and share no path; they run together.
  - Layer 2: T-0993 (CLI and guard) and T-0994 (MCP tool) both wait for T-0991, whose functions they call; they share no path and run together.
  - Layer 3: T-0995 (host API action and dashboard route) waits for T-0993: the action runs the command.
  - Layer 4: T-0996 (ADR, design, docs, conventions, serve's prompt) waits for all the others, whose behaviour it documents, and for TH-0162's answer.
