## Decisions

- Kept the planner's tasks and layers: 1) T-3095 and T-3096, no path in common; 2) T-3098 after T-3095, since it clears under T-3095's key in the same files; 3) T-3104 and T-3105 after T-3098, whose clear both call, no path in common; 4) T-3106 after T-3104, T-3105, T-3096, to describe them as built. Layer 1 and 3 tasks run at once, one sub-agent each.
- The budget key (T-3095): the provider when the run names one; else the harness name and its resolved program as the operator set it, or the adapter's default program (such as `claude-code meclod`, `claude-code claude`), followed by the word login and the folder when the container harness has a login (such as `container docker login /home/alex/.claude-rmh`). Arguments are not in the key: a harness change of arguments clears the state of the identity it had (T-3105) instead.
- The key is recorded on AgentRun at the gate, so the six end callers of budgetEnded key a run's end as its start was keyed without being changed; a run recorded before S-0720 keys as before, by provider or harness.
- Old shape (T-3095): an entry keyed by the bare harness name, as budget.json held before S-0720, still holds every start on that harness until it clears, by a probe that ends clean, by flai serve budget clear, or by a harness change on that harness: flai cannot tell which login set it, and letting every login start on it would repeat the limit for the one that set it.
- Criterion 1's 'so the next start goes as the probe': a clear leaves no state, so the next start on that login goes with nothing holding it, and a run of it that ends on the limit sets the state again, which is what a probe would learn. Read so; the tests assert the next start is not held.
- T-3098 locks budget.json with an OS file lock beside budgetMu, since flai serve budget clear and flai serve agent harness clear it from a flai process other than flai serve's.
- T-3104: flai guard refuses `flai serve budget clear` to every served agent and sub-agent (hostWrites in flai/internal/guard/hostconfig.go), as it refuses a write of the host configuration (ADR-0220), so no agent lifts its own usage-limit hold; the bare `flai serve budget` stays a read. The guard files were added to T-3104's touches.
- T-3105 also clears on `flai serve agent set`, which sets the command harness's program and arguments, and the journal-and-notice loop of the two commands is one helper, announceBudgetClears in flai/cmd/serve_budget.go, merged by the story's agent after the layer.
- T-3106's sub-agent found the old key wording in design/system/project-manifest.md, design/system/strategic-agents.md, docs/operators/runbooks/backup.md, and the inbox row of docs/users/flai.md; the story's agent fixed them in T-3106 and widened its touches.
- T-3123 added after the first close-out: the per-login key changes budget.json's contract with the MCP server and host API, and the guard gains a rule, so decisions.md asks for an ADR; ADR-0290 records both and refines ADR-0209 §5.
