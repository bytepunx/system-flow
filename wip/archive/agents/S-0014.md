# S-0014 Flow metric charts

## Context
Charts are the reason the front matter carries timestamps (brief, metrics.md). ADR-0016 means the numbers come from flai stats --json through the same wrapper the board uses, so the dashboard charts what the CLI computes and nothing is re-derived in TypeScript. The design names ECharts 6 imported per chart type; the dataviz guidance was loaded before any chart code and its validated reference palette adopted (both modes checked with the validator). Seven charts from metrics.md: cycle time scatter with p50 and p85, burn-up per epic and total, cumulative flow, time in state per item plus the share bar, throughput per week by nature, aging WIP against p85, estimate versus actual.

## Current state
All four tasks done, story in review. GET /api/stats runs flai stats --json through the ADR-0016 wrapper (since, type, by validated; cached per query; cache cleared on watcher change). src/lib/viz/palette.ts holds the validated categorical palette for light and dark with fixed slots for states and natures; src/lib/viz/charts.ts builds the seven chart options as pure functions (one axis, thin marks, legend for two or more series, tooltips, p50 and p85 reference lines, scatter capped at three colour groups); Chart.svelte loads ECharts core lazily and resizes with its container; /charts/[kind] has a kind switcher, window, type, and epic filters, a summary strip, the chart, the state-share bar under time in state, and a table view. 32 unit tests. Verified against this repository: API numbers, all seven routes, and two screenshots (cycle time, cumulative flow) reviewed. The visual check exposed the SSE crash, now fixed and tested. Lint, check, vitest, and all repo tiers green. Committed at review and pushed.

## Decisions
- Metrics are never computed in the dashboard: /api/stats is flai stats --json verbatim, cached per query until the watcher reports a change.
- The dataviz reference palette is adopted unchanged, validated in both modes; states and natures have fixed slots so identity never follows rank or filter.
- Scatter colours at most three groups and folds the rest into "other" (the all-pairs rule); every chart has one y-axis and a table view.
- ECharts is loaded from echarts/core with only the used pieces, lazily, so the explorer and board pages do not pay for it.
- The SSE stream helper owns its teardown: cancel and abort both route to one idempotent finish, and no controller call happens after close. A crash there had been taking the whole server down.
