# S-0099 The dashboard's favicon is the flai logo

## Context

The operator attached their flai logo (128×128 PNG) and asked for it to be the dashboard's favicon.

## Current state

Done. `flaiover/src/lib/assets/favicon.png` is the attachment, byte for byte, imported by `+layout.svelte`. SvelteKit's default `favicon.svg` is removed, and so is `auth.ts`'s allowance for `/favicon.svg`, a path nothing served, since the icon is bundled under `/_app/`, which needs no login. Checked in a browser against a dev server: the page's icon link serves `image/png`, 128×128, 4,828 bytes, the same as the attachment. The production build emits it as `_app/immutable/assets/favicon.*.png`. The flaiover suite (405 tests), lint, and svelte-check are clean.
