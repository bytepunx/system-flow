## Decisions

- The planner's twelve tasks are kept, as TH-0776's recommendation says. Dropped the touches `flai/internal/sync` and `flai/internal/claims`, which name no package.
- The trial-merge judge: `workitem.TrialJudge func(held, holder string) ([]string, error)`. It answers the paths that conflict when holder's branch merges at held's base, and an error when the trial cannot run. `Holds.WithTrial(j)` sets it. `Repo` gains a `Trial` field, and `Repo.Holds` applies it. With no judge, the verdict is today's.
- held's base is its own branch `story/S-held` when that exists, such as for a story sent back. Otherwise it is the main branch. The ready story has no branch yet, so main stands in for its base.
- With a judge, an overlap pair that `holdBy` finds holds only when the trial conflicts. The reason then names the conflicting paths. A clean trial holds nothing. An error holds as today, and the reason says why the trial could not run: no branch yet, or git older than 2.38. A story whose agent was just started in the same look has no branch yet, so one look still never starts two stories that overlap. A no-touches hold stays as it is. The pair memo is skipped while a judge is set, because branches move between looks.
- `storygit.NewTrialJudge(r execx.Runner, repo *workitem.Repo, files storygit.Files)` builds the judge, in `trial.go`. It takes `files` because the code that builds a `Files` (`issues.FilesIn`) imports storygit. Callers pass `issues.FilesIn(repo, repo.MainRoot, r, time.Now)`. It checks the git version once, and caches by the two heads' SHAs. It leaves out the generated and merged files that `withoutResolved` drops.
- The judge is wired where `Repo.Git` is set or the look opens its repo: serve's `look` and start check (T-2395), the MCP server and the CLI's project open (T-2404). The replay of past holds in `metrics/claims.go` stays without a judge, so it stays a record of the holds as they were.
- Layers: 1 is T-2388, T-2389, T-2391, and T-2393, with no file in common. T-2389 returns a plain func type, so it builds before T-2391 lands. 2 is T-2395 and T-2404, which need the judge (T-2389, T-2391), and T-2406, T-2408, and T-2410, which need T-2388's rules and ADRs. 3 is T-2412 (the check advisory and the convention), T-2414 (stats), and T-2416 (everything it documents).
