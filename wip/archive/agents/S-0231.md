# S-0231 Author LICENSE.md file

## Context

The repository had no license: the Dockerfile's OCI label said `UNLICENSED`, the package manifest named none, and nothing in the binary or the dashboard showed terms. The story asks for an adaptation of the PolyForm Shield License that grants free use to four classes (501(c)(3) nonprofits, educators and students at state-funded institutions, security researchers, start-ups under USD 1M revenue and USD 15M funding), needs a paid license for other commercial use, bars everyone from offering system-flow or a fork as a hosted service or licensing it, requires the license to travel with every copy, and ships the text in the docker image (Host › License), in the flai binary, and behind `flai license`.

## Current state

All four tasks are done and committed on `story/S-0231`:

- `LICENSE.md` at the root: the system-flow Shield License 1.0, PolyForm Shield's structure with Permitted Purposes (the four classes), Prohibited Uses (hosted services, licensing, competition, binding everyone), Notices requiring the full text with every copy in every form, and a paid-license pointer.
- `flai license` prints the text embedded from `flai/internal/license/LICENSE.md`, a copy the test `TestEmbeddedLicenseMatchesRepository` keeps equal to the root file; `--json` gives name and text; the goreleaser archives carry the file; `docs/users/flai-reference.md` regenerated.
- The image copies `LICENSE.md` to `/app/LICENSE.md`, the OCI licenses label is `LicenseRef-system-flow-Shield-1.0`, `GET /api/license` reads it (`FLAIOVER_LICENSE` overrides, a checkout falls back to `../LICENSE.md`), the `/license` page renders it, and the Host group gains License after Settings. Tests: server lib, API route, page component, site menu; `no-project-files.test.ts` accounts for the one read.
- Design (`flai-cli.md`, `flaiover-dashboard.md`, `docker.md`), user docs (`flai.md`, `flaiover.md`), operator docs (`index.md`, `settings.md`), and `README.md` describe the license and where it is shown.

The second verifier's close-out run passed whole: Go lint and every tier, markdown lint, `flai check --strict` with 0 warnings, flaiover lint, svelte-check, and 738 vitest tests. The docker image build is unverified because the daemon was not answering; `.dockerignore` re-includes `LICENSE.md` and the Dockerfile copies it, checked by reading. In review with TH-0067 open: the licensor's name, a paid-license contact, and three scope questions are answered there with stated defaults, which is what the text says now.

Observed, not fixed here: `design/tech/docker.md` still describes the image as holding flai, git, and ssh, which ADR-0031 and the Dockerfile say it no longer does; worth a remediation story.

## Decisions

- The license is titled "system-flow Shield License 1.0" and says it adapts PolyForm Shield 1.0.0 without the PolyForm name, because the PolyForm Project asks adaptations not to carry its name.
- The four free classes are exactly the story's; no personal noncommercial class and no non-US charity equivalence until the operator says so (TH-0067).
- The prohibition on hosted services and licensing binds every licensee, free or paid, and only a separate written agreement with the licensor can lift it, because the story's intent is to shield system-flow and its forks from being offered by another entity.
- The binary embeds a copy of `LICENSE.md` under `flai/internal/license/` rather than reading the root file at build time, because Go embeds nothing above its module and a build outside the scripts (goreleaser, `go install`) must still carry the text; a test keeps the copy equal to the root.
- The dashboard reads its own `LICENSE.md` from the image instead of asking flai on the host, because the license is the image's, not the project's; the read is accounted for in `no-project-files.test.ts`.
- No ADR: the license is a project decision contained to this story, recorded here and in the story's notes, not a change to structure, technology, a contract between parts, or a tool-enforced rule.
