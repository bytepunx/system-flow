# S-0048 Parent epic indicator on story cards on the board

## Context
Story cards on the board should show their parent epic in the bottom right corner. The card markup is inline in `flaiover/src/routes/board/+page.svelte`; cards come from `flaiover/src/lib/server/board.ts` through `GET /api/board` and already carry `parent`, not the parent's title. Component tests live beside components in `flaiover/src/lib/components` (see `AcceptConfirm.svelte.test.ts`). Work is in `.flai-cache/worktrees/S-0048` on `story/S-0048`.

## Decisions
- 2026-09-18, agent: the parent's title comes from the API as `parent_title`, not from the page resolving it among the cards it has. The server already reads every item, archived ones included, so the title is found whatever the parent's state, and a second consumer of the board API gets it too. The story's notes left this to refinement.
- 2026-09-18, agent: the card becomes `BoardCard.svelte` so the indicator can have a component test, which the criteria ask for; the page has no test harness of its own.
- 2026-09-18, agent: the indicator is a `span`, not a link to the epic, because the card is a single `<a>`; the story's notes put a clickable indicator out of scope.

- 2026-09-18, agent: the first dev server was started with the repository's dev script, which prints a login link holding the real dashboard token into its log. The log was deleted unread and the server restarted with a throwaway token file, so the real token was never read, shown, or passed to the browser tool.
- 2026-09-18, agent: the sideways scroll at phone width is outside this story (navigation bar in the root layout); recorded as I-0018, not fixed here.
- 2026-09-18, agent: the title got `break-words`, the only styling change to the card besides the indicator, so a long unbroken word cannot push the bottom row.

## Open questions
- `scripts/flaiover-dev.sh` echoes the login link, token included, to stdout, which lands in any log the caller redirects to. Proposed: print it only when stdout is a terminal. Not part of this story.
