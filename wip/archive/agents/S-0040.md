# S-0040 Document editing in the dashboard with commit through flai

## Context
The designer should be able to edit design, docs, and work item bodies in the dashboard and have the change validated and committed on main. ADR-0016 says the dashboard writes through flai, so the save is a flai command and the dashboard is a client of it. What exists: the document page (`flaiover/src/routes/docs/[...path]/+page.svelte`) renders a file from `GET /api/docs/file`, already shows the "being worked on by" warning from `touches` (S-0037) and the `Threads` panel with the document's headings (S-0038); `src/lib/server/flai.ts` spawns flai with `--json` and maps `rule:` errors to 400; the MCP server has the guard that keeps document reads inside design, docs, and wip (`docPath` in `flai/internal/mcpserver/server.go`). Work is in `.flai-cache/worktrees/S-0040` on `story/S-0040`.

## Decisions
- 2026-09-19, agent: saving is a flai command (`flai doc save`), not file writes in the dashboard's server, following ADR-0016; ownership rules live in flai only and the editor asks flai what may be edited (`flai doc show`).
- 2026-09-19, agent: the editor is a textarea with the explorer's renderer as preview; no editor library is added (fewest dependencies).
- 2026-09-19, agent: creating, renaming, and deleting documents are out of scope; the story says edit.
- 2026-09-19, agent: commits made from the dashboard are not pushed, like acceptances; S-0052 owns that question.

- 2026-09-19, agent: a save is refused for any finding the edit introduces, at any level, not only errors. Every document rule in `flai check` is a warning and this repository's gate is `--strict`, so refusing only errors would have validated nothing for design and docs files. ADR-0023 says so. Found when the refusal test saved a document with no title and it was accepted.
- 2026-09-19, agent: conflict is exit code 3 and refusal exit code 4 from `flai doc save`, with the payload as JSON on stdout under `conflict` or `refused`, so the dashboard can tell them from other failures without parsing messages.

- 2026-09-19, agent: the conflict diff names its two sides as `<path> (current)` and `<path> (yours)` and drops git's header lines, after the first browser look showed the absolute host path and a temp file name in it.
- 2026-09-19, agent: a failed commit is not a failed save; the result carries `commit_error` and the editor says "saved, but not committed". The commit step is a helper that returns its error so the linter's nilerr rule is met without a suppression on the save path.
- 2026-09-19, agent: the dashboard's trailer is `Co-Authored-By: flaiover <flaiover@localhost>`, set by the dashboard's server, not by flai, so the command line adds no trailer unless asked.

## Open questions
- Accepted ADRs are immutable by convention except for `superseded_by`. Should `flai doc save` refuse edits to an accepted ADR's body, for the designer too? Proposed: refuse, with the reason, and allow only `superseded_by` and `status`; not built in this story unless the operator says so, since the criteria do not ask for it.
