## Context

## Decisions
- No manifest change: the folder is <layout.design>/conventions, resolved through layout.design (ADR-0013).
- The generic documentation walk skips the conventions folder; the conventions rules own it, so a file is never reported twice.
- `flai prime` prints README.md first, then files by order; a missing folder is an error naming the fix, while check reports it as a warning so an older project still passes with a nudge.
- Draft conventions carry `status: draft` and state that nothing in them binds; prime still prints them so the agent knows they exist.
- The two empty placeholder files were scaffolded rather than deleted or left failing: the operator created them deliberately, and a scaffold is the smallest change that keeps the render valid without inventing rules.
