# S-0028 Operator runbooks and settings index

## Goal
Operator documentation meets the documentation convention: every configuration setting indexed, and runbooks for installation, updates, deletion, backups, restores, and migrations for flai and flaiover, with pointers to dashboards and tools. Closes issue I-0005.

## Acceptance criteria
- [x] docs/operators/settings.md indexes every flai config key, flag, environment variable, and flaiover container setting
- [x] docs/operators/runbooks/ has one page each for install, update, delete, backup, restore, and migrate, for flai and for flaiover
- [x] docs/operators/index.md links the settings index, the runbooks, and where the dashboard and tools are
- [x] I-0005 closed with a pointer to this story

## Tasks
- T-0424 docs/operators/settings.md indexes every flai config key, manifest key, and environment variable, and the flaiover container settings, and a test keeps it complete
- T-0425 flai reference writes an index of every flag into docs/operators/settings.md, kept current by a test
- T-0426 Runbooks for installing, updating, and deleting flai and flaiover
- T-0427 Runbooks for backing up, restoring, and migrating flai and flaiover
- T-0428 The operators guide links the settings index, the runbooks, and where the dashboard and tools are, and I-0005 is closed
