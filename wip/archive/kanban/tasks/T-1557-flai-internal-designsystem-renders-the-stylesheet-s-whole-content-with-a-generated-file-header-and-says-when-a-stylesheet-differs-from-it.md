# T-1557 flai/internal/designsystem renders the stylesheet's whole content with a generated-file header and says when a stylesheet differs from it

## Work

In `flai/internal/designsystem/stylesheet.go`, `Stylesheet` gives the generated stylesheet's whole content as ADR-0159 sets it out: a comment header saying it is generated by `flai design css --write` from the token file it names, and not to edit it, then `Tailwind`'s rendering. `Tailwind` in `css.go` gains the `@custom-variant dark` line ahead of `@theme`, so that `flai design css --tailwind` prints exactly what `--write` writes below the header, and its comment no longer says the selector is S-0385's to settle. `Stale` (or a name as plain) compares a file's content with it, ignoring line endings. Golden tests cover both. It waits for nothing in this story; it builds on S-0381's `Tailwind`.
