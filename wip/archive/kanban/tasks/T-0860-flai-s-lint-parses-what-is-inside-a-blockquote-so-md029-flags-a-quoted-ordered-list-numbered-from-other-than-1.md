# T-0860 flai's lint parses what is inside a blockquote, so MD029 flags a quoted ordered list numbered from other than 1

## Work

The parser in `flai/internal/mdlint/doc.go` marks a line that starts with `>`, and the lazy lines after it, as `kQuote`, and parses nothing inside them. So no list in a blockquote is judged; `rules.go` says so beside MD007. Make it parse a blockquote's content as blocks of their own, with the `>` markers and the one optional space after each taken out, and nested quotes handled. Report each finding on the original line, as markdownlint-cli2 does.

1. Add a fixture, `testdata/cases/blockquote.md`. Give it TH-0101's entry, which quotes two steps as `> 3.` and `> 6.`. Add quoted ordered lists that run 1/1/1 and 1/2/3, a quoted bullet list, a list nested in a quoted list, a nested quote, and a quote that ends at a blank line with a list after it.
2. Regenerate `testdata/cases/expected.txt` with `scripts/mdlint-fixtures.sh`, which runs markdownlint-cli2 at the version `lint-md.sh` runs.
3. Change the parser so that `TestFixturesMatchMarkdownlint` reports nothing missing and nothing extra, for MD029 and for every other rule that now sees quoted content: MD004, MD007, MD022, and MD031. Where a rule cannot place a quoted case, report nothing rather than something markdownlint would not, as ADR-0061 says.
4. Correct the comment in `rules.go` that says lists in blockquotes are not parsed.

This task waits for no other task. It is the fix, and its fixture is the test that reproduces I-0070.

## Done when

- `testdata/cases/blockquote.md` holds TH-0101's `> 3.` and `> 6.` lines, and `expected.txt`, regenerated by `scripts/mdlint-fixtures.sh`, has MD029 on both.
- `TestFixturesMatchMarkdownlint` passes, with mdlint reporting MD029 on those lines.
- `TestRepositoryLintsClean` passes: no markdown file in the repository gets a finding.
- `scripts/flai-test.sh` passes.
- A thread entry or item body with `> 3.` is refused by flai, naming MD029. A test through `Repo.LintGuard` or `Config.Lint` shows it.
