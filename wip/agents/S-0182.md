# S-0182 Find and fix how flai serve 1.23.0 started an agent for a story the board showed held

## Context

The cause, found from what survives on this host, pending TH-0049 for the other host's journal:

- The evidence for 2026-09-29 is not on this host. That serve ran on a Linux host (pid 2077672). This host's `~/.flai/serve/journal.jsonl` starts 2026-09-26 and has no 2026-09-29 entry.
- flai 1.23.0's launcher (`look`, `flai/internal/serve/agents.go`) checks `holds.Of` before every start, with the same `Repo.Holds` the board and `inbox` use. Claims overlap by `PathsOverlap`, which pairs a file with its directory both ways. The hold code is unchanged since then.
- `resume()` cannot have started either: S-0144 (created 01:04:15Z) and S-0145 (created 01:57:32Z) had no earlier run.
- The operator's Start agent (story page, `agent.start`, `flai serve agent start`, S-0115) overrides a hold by design (S-0129). In 1.23.0 it gives the agent the launcher's prompt word for word ("started by flai serve ... because it entered ready"), with `FLAI_STARTED_BY=flai-serve`, and journals a `serve.agent` entry by `flai serve` next to the `agent.start` entry by the operator. Its "agent started for a held story" warning goes only to the log of the `flai serve agent start` process. An agent started that way can only report what I-0050 records.
- S-0145 entered ready at 01:57:54Z and its agent started at 02:10:59Z, 3.5 minutes after S-0144 was accepted (02:07:25Z), with S-0138 in progress throughout. The launcher looks on every kanban change and every minute, so a launcher start would have come at 02:07:25Z, not 02:10:59Z. A press of Start agent fits that gap.
- This host's `serve.log` for 2026-10-01 shows holds working: each ready story it skipped names the right holder, and each start (S-0174 and S-0175 at 07:48:04Z, S-0179 and S-0180 at 08:18:49Z, S-0188 at 08:30:29Z) came right after its holder was accepted.
- `resume()` is a real bypass, though not this one. It restarts an asked agent once the thread is answered, for a story in any state but done or cancelled. A story sent back to ready meanwhile is started past its hold and the limit.
