## Decisions

- Kept the planner's two tasks as written. Layers: T-3525 alone, then T-3527, which waits for it because it measures and documents the batched read T-3525 builds. No two tasks share a path.
- Worked T-3525 myself rather than through a task sub-agent: its code and tests were already read into this session for planning, so a fresh sub-agent would read them all again, and a fork would carry this whole session's context. The delegation convention says not to delegate what is quicker done here.
- Each file of a batched diff is found by its exact header, `diff --git a/<path> b/<path>`, against the record's own paths, with `--src-prefix=a/ --dst-prefix=b/` and `core.quotePath=false`. A path git still quotes (a quote, a backslash, or a control character) matches no header, so it falls back to a diff of its own. That keeps the answer right for every path while the usual record runs one diff.
- FindUndone, which the sync runs once per rebase, keeps its per-path diffs: I-0349 is about the read every board.get, acceptance preview, and queue look runs, and FindUndone is not on that path.
