# S-0131 flai stream sync reports conflicts with other open story branches and changes outside the story's touches

## Context

The safety net of ADR-0046 at sync: after the rebase, `flai stream sync` trial-merges the story branch with every other open story branch (`git merge-tree --write-tree`), reports conflicts to both stories, and lists the paths changed outside the story's claim. Code in `flai/cmd/branch.go` and `flai/cmd/stream.go`; tasks T-0477..T-0480.

## Current state

Started while held by S-0130 on `flai/cmd` (host flai 1.18.5 predates holds); TH-0023 asks whether to go on, and work goes on meanwhile. S-0130 changes `flai/cmd/edit.go`, not the sync code. T-0477 in progress.

## Next steps
1. T-0477: trial merge against every other open story branch, text and `--json`, git 2.38 minimum, integration test.
2. T-0478: conflict thread written by `flai`, deduplicated per pair, resolved when clean.
3. T-0479: paths changed outside the claim.
4. T-0480: docs, all tiers, lint, `flai check --strict`; move S-0131 to review.

## Decisions

- A conflict found at sync reaches the agents and the designer as a thread written by `flai` on the story that synced, one per pair of stories: threads already appear in the MCP `inbox` of every agent whose name is not the last author and in the dashboard's designer inbox, so no new channel or inbox kind is needed. A later sync with the same paths writes nothing, new paths add an entry, and a clean merge resolves it.
- Sync still exits 0 when another branch conflicts: its own rebase succeeded, and the conflict is the pair's to settle, not a failure of this sync.
