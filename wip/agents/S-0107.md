## Decisions

- Writes whose success ends their own connection (serve or all, and upgrade) are sent with `retry: false`, and the panel reads the route's 502 for them as the work going ahead. Found live: the retry restarted serve twice. The root cause is flai's journal, and is raised on S-0106 as TH-0006.

- The flaiover side is built now, against the host contract in S-0106's code and narrative: `host.status` returns `internal/host.Status`, and `start`, `stop`, and `restart` take `serve`, `mcp`, or `all`. The flai side and the live check wait for S-0106 (T-0381). That keeps the two stories off each other's files until S-0106 lands.
- The MCP servers are one row with one set of controls, because the host acts on them as one `mcp` process group. The row lists each project served. AC1 names "the MCP sub-process" in the singular.
- Serve's Start cannot be reached from the dashboard once serve is stopped: the dashboard talks to the host through serve. The row keeps the button, which is disabled while serve runs. Stop warns that only a shell on the host (`flai host start serve`) brings serve back.
