# S-0035 flai dashboard runs from a private registry or a local build

## Context

## Current state
Complete. `flai dashboard` logs Docker into a non-Hub registry on an unauthorized pull (token from `GITHUB_TOKEN`, `GH_TOKEN`, or `gh auth token`; login name from `gh api user`, `GITHUB_ACTOR`, or a placeholder) and retries once, or fails naming `gh auth refresh -h github.com -s read:packages`. `--build` builds `flaiover:local` from `flaiover/` in the monorepo. The container publishes on `dashboard.bind`, default `0.0.0.0`, settable in the manifest, config, or `--bind`. Verified for real: `flai dashboard --build` runs the dashboard at port 4242 on every interface (`docker port` shows `0.0.0.0:4242`, health answers on the host IP). The login path is covered by tests only: the operator's gh token lacks `read:packages`, so the real GHCR pull is still refused until `gh auth refresh -h github.com -s read:packages` is run or the package is made public. Story in review.

## Next steps
1. Operator: `gh auth refresh -h github.com -s read:packages`, then `flai dashboard --pull` to confirm the registry path end to end (or make the GHCR package public).
2. Operator review and `flai accept S-0035` (feature story: flai minor, flaiover patch).

## Decisions
- Default bind is `0.0.0.0` on the operator's instruction (2026-09-17), which conflicts with the earlier security posture text ("keep it bound to localhost"). The posture now says the host must be private and documents `dashboard.bind: 127.0.0.1` and `--bind` as the way to restrict. Recorded here rather than as an ADR because it is a runtime default, not an architecture change.
- Registry login is attempted only for non-Hub registries and only after an unauthorized pull; the token goes through stdin (`--password-stdin`) and is never logged. A new `RunInput` on `execx.Runner` carries it.
- `--build` is limited to the monorepo (needs `flaiover/Dockerfile`); elsewhere the published image is the path.
- The compose stack publishes flaiover on every interface for consistency and keeps the LGTM collector and Grafana on loopback.
- The template manifest now carries `bind: 0.0.0.0` so new projects see the default and how to change it.
