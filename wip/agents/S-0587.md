# S-0587 Default harness and agent should work out of the box

## Context

A new project has no default agent, flai has none of its own, and the host's agent settings are shared by every project. So once the `agent` host action is on, a new story's Start agent is refused for naming no harness. ADR-0261 records the fix.

## Decisions

- ADR-0261 settles the planner's four open choices.
  - The built-in default is `claude-code` with no model. Without a model, the harness picks its own default, which does not go stale with a model release.
  - It comes after the host's command, so a host that relies on the command keeps it. This follows ADR-0251's consequence, which I keep rather than reverse.
  - The host's agent settings are per project as `agent.projects.<root>`, over the host-wide values as the fallback. `--all-projects` matches `flai serve enable`.
  - Refusals carry the `/settings/<page>` path as plain text, and the dashboard links it. No error shape changes.
- Planner's tasks reviewed and changed:
  - T-2578 is narrowed to the manifest's built-in agent and `Repo.StartAgentOf(it, commandSet)`. `AgentOf` alone cannot know the host's command, which comes before the built-in. `create.go` and the serve test go to T-2582, which wires the start sites.
  - T-2582 also touches `harness.For` (`harness.go`, `harness_test.go`), whose refusal carries the same words.
  - I dropped the planner's idea of refusing a harness whose program is not on `PATH`. The criteria do not ask for it, it needs a lookup per harness kind (the container harness runs `docker`), and an exec failure already reports it.
  - T-2583 waits only for T-2577: it renders the ADR's path form and needs no serve code.
  - T-2580 follows the ADR's shape (`agent.projects`) in place of a `*` entry.
- Layers:
  1. T-2577, the ADR, done.
  2. T-2578, T-2579, T-2580, T-2583. No path in common, and each needs only the ADR.
  3. T-2581 waits for T-2580's per-project `settings.*` writes. T-2582 waits for T-2578's resolver and T-2580's per-project command.
  4. T-2584, the docs of what shipped.
- Overlaps:
  - S-0406 also claims `harness.go`. I told it on MS-0346 that S-0587 touches only `For`'s refusal messages.
  - S-0589's and S-0586's docs notices (MS-0344, MS-0345) do not break this story. Both are settled.
