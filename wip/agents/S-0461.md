# S-0461 The review, charts, and documents pages navigate within themselves from the left sidebar

## Context

## Current state

T-1984 (PageSidebar links, labels, header) and T-1965 (review page sidebar) are done and committed. DiffView gained an ids prop and a show function for the review page. Criterion 1 is ticked.

## Next steps

1. Work T-1966 (charts) and T-1967 (documents) together through task sub-agents.
2. Review, close, and test each.
3. Work T-1968 (docs), then the close-out and review.

## Decisions

- Kept the planner's four tasks and added T-1984. `PageSidebar` writes each entry as a hash link and has nothing above its entries, so the charts page cannot route to `/charts/<kind>` from it and the documents page cannot put `DocTree` in its column. T-1984 adds an entry `href` and a `header` snippet, once, so T-1966 and T-1967 do not both change `PageSidebar.svelte`.
- Layers: T-1965 and T-1984 first, together: they share no path. T-1966 and T-1967 second, together: both wait for T-1984 and share no path. T-1968 last: it waits for all four to describe the pages as built.
- T-1965's sub-agent opened a file's diff panel by clicking DiffView's toggle and set row ids through the DOM. Replaced that with DiffView's own `ids` prop and `show` function, and added `DiffView.svelte` to T-1965's touches.
- The review sidebar lists Issues, Checks, and Verification after Release plan when the page shows them, beyond criterion 1's five, so that every section is one choice away. Threads moved up, between State and Changes, to match the criterion's order.
- The documents page reads its headings' ids and text from the rendered HTML rather than from `headingsOf`: the renderer slugs a heading's plain text and numbers repeats, so slugs of `headingsOf`'s raw markdown would miss headings with inline code or links. `Threads` still gets `headingsOf`.
- A chart kind is a linked entry, not a hash pane, since a hash pane cannot route to `/charts/<kind>`.
- Added T-2010, an end-to-end test at a phone's and a desktop's width, so that criterion 4's "no page scrolls sideways" is verified in a browser, not by class names under jsdom. It runs beside T-1968: they share no path.
