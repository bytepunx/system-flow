The MCP server is given a runner; `inbox` lists `unpushed` on every call while true and the `board` tool carries it; the instructions say what an agent does. Tests with real git and bare remotes for each case of the detection, the command end to end (an acceptance made with `--no-push`, dry run, push, second run, ordinary commits, divergence), and the MCP tools. `make flai-test` passes, 0 lint issues.

flaiover: `GET /api/unpushed` asks flai (`push --pending --dry-run`); `UnpushedNotice.svelte` on the board and on an accepted story's page, asking again on every board change, on window focus, and each minute while showing; no button. Component tests and a test through the real flai binary with a scratch remote. `make flaiover-test` (264 tests) and the build pass.
