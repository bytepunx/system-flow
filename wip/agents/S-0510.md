## Decisions

- Kept the planner's five tasks, their `after`, and their touches. T-2164 gains `flai/internal/manifest/agent.go` and `agent_test.go`, where the `Agent` struct lives; T-2165 gains `scripts/agent-image-test.sh`.
- Layers. Layer 1 is T-2164 (the manifest key) and T-2165 (the build and this repository's layer): they wait for nothing and share no path. The manifest reader ignores keys it does not know, so `system-flow.yaml` can name the layer before T-2164 lands. Layer 2 is T-2171 (the check) and T-2172 (serve runs the layer): both read the key T-2164 adds, so both wait for it, and they share no path. Layer 3 is T-2176 (the live run and the docs): it describes and runs what the other four built.
- `agent.image.layer` is a field of `manifest.Agent`, the project's alone. `Agent.With`, which copies the project's agent into a new story and merges the roles' agents, does not carry it. A story's agent never names a layer, and a story made after the key is set does not gain it.
- The layer's image is `flai-agent-<key>-<inner>:local`, `flai-agent-sf-claude-code:local` here, given by one manifest helper that the script's docs, the check, and serve all name. When the manifest names a layer, it wins over the host's `--image` for the container harness.
- T-2165 changes `flai/images/` and `scripts/agent-image.sh`, which the protected list holds since S-0508. So the story's agent makes those writes itself, through `permission_prompt`, rather than through a sub-agent.
- Criterion 5's live run needs the installed `flai serve` to carry the layer, and the close-out needs git inside the container (I-0215, S-0517). Asked on TH-0814 whether to move it to S-0565, as TH-0812 did for S-0508's criterion 6 (D-0461).
