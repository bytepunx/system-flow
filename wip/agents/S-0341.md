## Context

Story S-0341: `flai verify` reuses the tiers its last run passed when the head, the base commit, and the tiers are unchanged. The planner drafted five tasks; they are kept as drafted.

## Decisions

- The plan keeps the planner's layers. Layer 1 is T-1343, the record and the resume, which everything else reads. Layer 2 is T-1344 (CLI) and T-1346 (review page): both wait for T-1343's `reused` state and `reused_from`, and share no path. Layer 3 is T-1347 (close-out), which waits for T-1344's last line, and T-1351 (docs), which waits for T-1344 and T-1346 so that it describes what was built.
- T-1343 is worked by the story's agent, not a sub-agent: its code was already read while reviewing the plan. Layers 2 and 3 go to task sub-agents, run together.
- The record gains `base_commit`. It had only the main branch's name, and criterion 1 asks for the main commit. A base git cannot resolve leaves it empty, and an empty one never resumes.
- The fingerprint hashes the manifest's tiers as declared and each selected tier's name, directory, and argv. A change to `tests`, a command, or the selection changes it.
- A reused step keeps the last run's command, exit code, and duration, and gains `reused_from`. A step the last record had reused keeps its `reused_from`, so a chain names the run that ran it.
- Layer 2: `flai task done T-1346` committed T-1344's uncommitted files too, as 5ccb156 under T-1346's subject (I-0108, bumped). The commit is left as it is, since S-0232 and S-0322 were told its hash. T-1346's touches were narrowed back to its three flaiover files, and T-1344's widened to `docs/operators/settings.md`, which `make flai-reference` regenerates. For layer 3, each task's files are committed by hand before its `flai task done`.
- T-1344: `--fresh` with `--last` is ignored rather than refused, since `--last` runs nothing.
- T-1347: the close-out streams verify's output through `tee` and passes its exit status through a file. It appends verify's `(reused …)` note to its own last line only for a pass or a stop at flai verify. `template/root/scripts/close-out.sh` is left as it is: a template project's verify resumes without it, and only the note on the last line is missing. Changing it is a template change outside the story's touches.
