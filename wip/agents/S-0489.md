# S-0489 Host page under configuration

## Context

The Host page exists at `/host`, but since S-0458 only the top bar's pills link it. The one refusal by host in the dashboard is the `/api/events` upgrade's 403 when the `Origin` host is not the `Host` header (`flaiover/src/lib/server/events-socket.ts`). The dashboard has no form actions, so SvelteKit's CSRF check does not apply. adapter-node and `server.js` refuse no `Host`: a GET with `Host: flow.example.com` against the running dashboard got the same 303 to login as one with its own address.
