- Followed ADR-0292 over the planner's wording, as the story's Notes ask: the request is flai kluster deploy|teardown S-nnnn --job and the MCP tools kluster_deploy and kluster_teardown, not a new subcommand; the key is kluster.agent_namespaces, default 2, 0 allowed (turns deploys before review off).

- The kluster event (ADR-0292 §5) and wait_for_events not ending while a kluster job runs are built here, as the way the agent waits; they were missing from the planner's tasks and go in T-2876 and T-2887.
