## Decisions

- The criteria and tasks follow ADR-0295 point 7, the accepted ADR S-0733 wrote, in place of the plan's assumed `flai serve agent harness container --build` and `--no-auto-image`. The settings are `agent.projects.<root>.image.command` and `.image.auto`, set by `flai serve agent image command` and `flai serve agent image auto`, and the command gets the `FLAI_IMAGE_*` variables. The story's Notes said the ADR might rename them. So criteria 1 to 3 were reworded, and what each asks is the same.
- The settings are per project only, with no host-wide fallback, since ADR-0295 names only `--project <root>`.
- A development flai's build from the tree stays as S-0740 left it. ADR-0295 point 3's 'with none named, the job fails' is for S-0760, which makes `scripts/agent-image.sh` this repository's command, and changing it here would break this host's builds before that.
- The operator's build command is not retried on a network failure, as flai's own pull and build are, since flai cannot tell what failed inside another's command. The stall limit still applies.
- Plan: layer 1 T-3190 (config, read by all); layer 2 T-3191 (CLI, view, guard) and T-3192 (runner, Ensure, flai image ensure), which share no file and run together; layer 3 T-3194 (image job and start), after T-3190 and T-3192, whose command Ensure runs; layer 4 T-3198 (docs), after T-3191 and T-3194, whose commands and behaviour it describes. T-3191 moved from serve_harness.go to a new serve_agent_image.go, and T-3192 gained flai/cmd/image.go.
- T-3191: the image settings are shown in `hostSettings` (`serve_view.go`), so the dashboard's settings.get and `flai serve settings --json` both carry them. `flai serve agent image` was added to `serveReads`, so strategic agents may read the settings, while ADR-0220's rule still refuses every write. Both are the story agent's review fixes.
- T-3192 ran in its own task worktree, since it and T-3191 both compile `flai/cmd`. Its diff was applied to the story worktree, with no shared file.
- In `build` mode, `FLAI_IMAGE_STALE` lists every image, and in `layer` mode only `layer`, so that `flai image build` never hands the command an empty list (T-3192).
