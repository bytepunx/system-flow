- T-3059's scratch check, 2026-11-11, Claude Code 2.1.322 on claude-haiku-5-5: claude -p in a scratch git repository with --add-dir <outside> --permission-mode acceptEdits --allowedTools Bash,Monitor, asked to have a general-purpose sub-agent Read a file in the outside folder and Write another there with the Read and Write tools. The sub-agent's Read and Write (parent_tool_use_id set) both succeeded, permission_denials was empty, and the written file held the marker. So a sub-agent inherits the session's --add-dir, as ADR-0289 §3 rests on. Without --add-dir, I-0265's instances show such reads are refused.
- T-3054 also needed two paths outside its touches, made by the story's agent: flai/internal/guard/hostconfig.go counts --outside as a write of the host configuration, so no agent grants itself a folder (ADR-0220), with its test; and flai serve settings (serve_settings.go, serve_view.go) shows a harness's outside folders, only when set, so the settings JSON of a harness with none is unchanged.
- S-0720 was accepted while T-3054 closed; the sync rebased clean onto it, and T-3059's flai test over flai/cmd, flai/internal/serve, and flai/internal/harness passed after it, which covers the overlapped paths.
- T-3063 ran in its own worktree (task/T-3063) beside T-3064 in the story's, since both change the harness package and one's half-done edit could fail the other's tests; its four files were copied back, tested with T-3064's, and committed apart. The task branch and worktree are removed.
- The start prompt names Read, Grep, Glob, Edit, and Write as refused outside the granted folders, not Monitor as ADR-0289 §6 words it: with Monitor in the default --allowedTools it is never refused, and Edit falls to permission_prompt as Write does. The ADR's decision, that the prompt says what is refused, stands; only the list is the accurate one.
- The close-out and check containers (ContainerCommand) mount no outside folder: they run flai verify and the project's tiers, which read only the worktree and the main checkout.
