# S-0518 flai guard does not run as the hook inside the agent container, and the hook lets every call through when the guard cannot start

## Context

Remediates I-0216: the `PreToolUse` guard hook allows every call when `flai guard` cannot start, and inside the agent image this repository's `scripts/flai.sh guard` exits 127 for want of `go`. The plan on TH-0688 was approved: the hook refuses only on exit 126 or 127, and `scripts/flai.sh` falls back to the installed flai when `go` is absent.
