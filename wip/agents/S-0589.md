- **Cause.** I-0300's guess does not hold. `(*launcher).look` (`flai/internal/serve/agents.go`) reads the `agent` action at every look, on every change under `kanban/` and `threads/` and every minute, and starts a ready story that has had no run since it entered ready, whenever it entered (ADR-0041). `~/.flai/serve/serve.log` for flai-scratch-import: 08:25:49Z `agent not started` (action off); 08:26:06Z `flai serve enable agent`; 08:26:49Z `agent not started`: `S-0001 names no harness, and no command is set on the host`; 08:35:18Z Start agent refused for the same reason; 08:42:02Z the default agent set with harness claude-code; 08:42:14Z S-0001 started. So the stall was the imported project's default agent naming no harness, which S-0587 ("Default harness and agent should work out of the box") owns. The operator saw no journal entry because the journal records only starts and failures; the reason was in `serve.log` and the story's `waiting`.
- **Solution proposed, as the goal asks.** No change to the launcher. A test pins the instance as it happened (T-2573), the operators guide stops reading as if a story already in ready waits for Start agent (T-2575), and I-0300 is closed naming S-0587 (T-2576). The fix for the missing harness is not built here: it is S-0587's scope, ready on the board.
- **The planner's plan, reviewed.** T-2573 rewritten from "reproduce a failure" to "pin the behaviour", touching `agents_test.go` only: no serve-level test is needed, as the cause is not in the serve loop. T-2574 (fix the launcher) cancelled: there is nothing to fix. T-2575 and T-2576 now wait on T-2573 instead of T-2574.
- **Layers.** 1: T-2573. 2: T-2575 and T-2576, which share no path and run together; both wait on T-2573, whose test is what the docs and the closing reason cite.
- **Left alone.** The planner noted that the project loop's `time.After(time.Minute)` in `serve.go` is made again on each pass, so wakes more often than a minute could delay the minute look. Here it did not: the look came 43 seconds after the enable. No measurement shows it happening, so it is not changed (code-quality.md: no change without a measurement).
