## Decisions

- The plan is the planner's four layers, one task each, run one after another: T-3173 (the key) → T-3174 (the build, which reads the arguments) → T-3175 (ensure and --layer, which call the build) → T-3176 (the documents, which describe all three). Each reads what the one before it writes, so none run together.
- ADR-0295 §4 is the shape: `agent.image.args`, a map of literal values beside `layer`. flai always passes `BASE` itself. The Dockerfile's ARG defaults stay its own, and they enter the recipe through the Dockerfile's bytes. The recipe label (§2) is `Recipe(dockerfile, "", args)`, which already leaves out `BASE` and `FLAI_VERSION`.
- T-3173 also touches `flai/internal/manifest/agent.go` and `agent_test.go`: `AgentImage` and its `problems` live there, not in `manifest.go`.
