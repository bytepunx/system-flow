# S-0127 Threads should visually delineate between agent text and operator text

## Context

Thread entries on every page with threads (`flaiover/src/lib/components/Threads.svelte`, used by the item, review, document, and editor pages) all looked alike: a grey time and author line over the text, since S-0126 rendered as markdown. Nothing set the operator's entries apart from an agent's.

## Current state

T-0460 done and committed on `story/S-0127` (5d88883). `GET /api/threads` marks each entry `operator: true` when its author is the manifest owner (`designer` without one); `Threads.svelte` shows operator entries right-aligned in a `bg-primary-soft` bubble with a primary border, agent entries left-aligned in a `bg-raised` bubble, each still with its time and author. Tests: `src/routes/api/threads/threads.test.ts` (owner marked, and only the owner; `designer` fallback) and a new case in `Threads.svelte.test.ts` (side and colour). `scripts/flaiover-test.sh` passes: prettier and eslint clean, svelte-check 0 errors (the existing `NewItemForm.svelte` warning), 70 files and 494 tests. A `vite build` emits the new classes in the CSS. Not viewed in a running dashboard. `design/system/flaiover-dashboard.md` and `docs/users/flaiover.md` updated. The story is in review.

## Next steps

1. Operator reviews and accepts S-0127.

## Decisions

- The operator is the manifest's `owner`, else `designer`: the same person flai writes the dashboard's threads as and counts as the designer in its inbox (`owner()` in `flai/internal/hostapi/writes.go`, `inbox.designer`). Everyone else is an agent.
- The server marks entries, not the page: `/api/threads` already has the manifest cached, and the page makes no second request. The mark is a boolean on the entry; the thread files and flai are unchanged.
- Operator right in the primary tint, agents left in the neutral raised tint, as chat layouts do; both use theme tokens so light and dark themes follow.
- The thread file itself, opened in the document explorer, is left as flai writes it: the story is about viewing a thread, which is the Threads panel.
