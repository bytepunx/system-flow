- A defined role's container and cache are named by its name, not its verb, so two defined roles that share a verb do not share a cache.
- T-2976's sub-agent found flai serve's role.go spawned a defined role with nothing on standard input (spawnGated), so pilot would read an empty request; fixed in T-2976's commit by passing spec.Stdin as the built-in roles do, and removed the now unused spawnGated.
- A defined role whose name is a built-in verb (plan, orchestrate, analyze, curate) is refused on the container harness, since its cache folder would be that role's; roles' own check does not forbid such a name.
- pilot reads the one file <design>/workflows/roles/<role_name>.md with roles.Parse rather than roles.Load, for a clear refusal per case; Check refuses a role_name that is not kebab-case, so it holds no path.
