# S-0060 Operators create ADRs from the dashboard

## Context
The operator wants to record a new architecture decision from the ADRs page by writing it in markdown, with the number, file name, front matter, date, and index row supplied behind the scenes. Today ADRs are made by copying `design/adrs/0000-template.md` by hand, taking the next number by looking, and adding a row to `design/adrs/README.md` by hand; flai has no `adr` command, `flai check` does not look at the index, and the dashboard's ADRs page has no write action. This story is mostly flai: the command, the index, the check rule, and then a form that is a client of them. Work is in `.flai-cache/worktrees/S-0060` on `story/S-0060`.

## Current state
Pulled as the next ready story in the operator's order, with S-0063 and S-0059 in review. The branch is based on `story/S-0059`, not on main, because this story reuses S-0059's one-step creation pattern, its endpoint shape, the flai wrapper's `--json` placement, and its form; none of that is on main until S-0059 is accepted. In-progress with five tasks, T-0233 to T-0237. No code changed yet.
