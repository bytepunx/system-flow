## Decisions

- The planner's five tasks are kept as drafted; the operator confirmed them on TH-0424. Layers: T-1493 (the ADR) alone, since the others build what it decides; T-1494 (verify's reuse, Go) and T-1495 (the close-out loop, both scripts, changelog) together, with no path in common; T-1496 (docs and the convention) after both, since it describes what they built; T-1497 (close I-0136) last.
- The patch id is taken from the merge base to HEAD, and only from a clean worktree: a report taken with uncommitted changes records none, so nothing is reused across a rebase from it. The paths that send tiers back are those changed between the report's merge base and this run's, not between the two base commits: the sync step passes over wip-only commits (ADR-0135), so the report's merge base may be older than its base commit.
- The ADR is written by the story's agent, not a sub-agent: it is short, and it fixes the rule T-1494 and T-1495 build.
- Work stays on the confirmed patch-id gate rather than a looser per-path comparison of the branch's own change. One consequence goes in the ADR: when a round's commit step commits issues that `--record-issues` wrote, the patch changes, so the next round reuses nothing.
- In this repository the integration and smoke tiers select `flai/**`. An acceptance that changes flai therefore still runs them again. The gain there is the close-out's own loop, which saves the agent's round trip. An acceptance that changes no flai path, such as docs, flaiover, or the template, saves the Go tiers too.
