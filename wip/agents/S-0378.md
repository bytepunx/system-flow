## Decisions

- The planner's tasks are kept as drafted. Layers: 1 T-1514 and T-1515, which share no path; 2 T-1516 (after T-1514, both change `flai/internal/hostapi/writes.go`), T-1517 (after T-1514 and T-1515, whose host methods it calls), and T-1518 (after T-1515, whose findings it lists; it uses T-1517's endpoint shapes); 3 T-1519 (after T-1518, whose `openEditor` it calls); 4 T-1520 (after T-1516, T-1517, and T-1519); 5 T-1521, the ADR and the docs, last.
- TH-0436 is open with the orchestrator's recommendation awaiting the operator: save on a story's branch through a new ADR refining ADR-0023, and exit 4 with the findings as data for `flai accept --json`. The orchestrator moved the story to ready, so the work follows that recommendation; T-1521's ADR records both, and an answer otherwise changes T-1514, T-1516, and T-1521.
- `doc.lint` is listed in the dashboard's `REQUIRED_METHODS` rather than kept optional as T-1517 planned: `contract_test.go` holds that list and flai's methods to one contract, and a missing method only raises the dashboard's notice to the designer, never refuses the connection. Committed with T-1515, whose touches gained `agent.ts`.
- T-1514 also registers `flai doc lint` in `flai/cmd/doc.go` (T-1515 could not without touching it) and regenerates `docs/users/flai-reference.md` and `docs/operators/settings.md`, so `cmd`'s reference test stays green; its touches gained them.
- T-1514's sub-agent added a refusal the task did not ask for: a story worktree not on `story/S-nnnn` (mid-rebase, detached) is refused, so a save never lands on another branch. Kept. Refusals of a wip path or a story without a worktree are plain errors (exit 1); exit 4 stays for refused content, as ADR-0023 has it.
- T-1516: only `flai accept --json` exits 4 on the ADR-0140 refusal; the text refusal keeps exit 1, since scripts read it today. Each finding carries `tier`, `checkout` (`main`, or `story` with `story`), `path`, `message`, and, when markdownlint gives them, `line`, `column`, `level`, `rule`, `alias`. `accept.run`'s Refused error carries `{id, reason, findings}` as data. The refusal's findings come from the markdown tier's last lines of output, as its text did before; a refusal with very many findings lists the last ones only.
- T-1517: a host flai that lacks a method now answers 501 on every route, not 500; nothing depended on the 500.
- T-1518: the editor keeps the dialog open after a save, so its notice can be read; `onsaved` lets a caller close it. Lint errors other than 501 show a muted "Could not lint" line.
- T-1519: a link in the open document's own preview or threads would replace it in the dialog, so `openEditor` asks before replacing a document with unsaved changes; the dirty flag moved into `editorState` (fixed in T-1519's close, its touches widened to `editor.svelte.ts` and `EditorDialog.svelte`). Not editable from a link: `wip/archive/`, `wip/threads/`, `design/issues/`, `wip/agents/index.md`, as `docedit.ModeOf` has them; the layout defaults to design/docs/wip, since the client holds no manifest.
- T-1520: Accept on the review page is enabled again once each listed file has been saved at least once; a file the editor cannot open does not hold it. The board's and item page's refusal notices link their paths through a new `links` option of `DismissibleNotice` (touches widened). A wip path opens on the main checkout even from a story's page, since flai refuses a wip path with a story (`editLink` drops the story).
- The verifier found that a text refusal for the main checkout's uncommitted files (from the board's move to done, the item page, or Review's text fallback) linked its files with the story. `linkSegments` now drops the story when the text names "the main checkout's uncommitted files", flai's own wording in `accept_markdown.go`; the structured findings on the review page already carried their checkout. Making `item.move` answer the findings as data, as `accept.run` does, would remove the text match; left for a later story.
