# S-0086 The host flai connection banner says 'not connected' even when a flai is connected but too old

## Context

Found while diagnosing an operator report: `flai serve` kept running an old in-memory version after `flai self-upgrade` replaced the binary on disk (self-upgrade cannot restart an already-running process). `/api/agent` already carried the true story (`connected: true`, `error` with the version, what is missing, and the fix commands); only the dashboard's own wording collapsed it into "not connected".

## Current state

Done. `HostFlaiBanner.svelte` and `HostFlai.svelte` (the header badge) both branched on `hostFlai.usable` (`connected && !error`) to pick their message; both now branch on `status.connected` itself instead, so a connected-but-unusable flai reads its own message (`status.error` verbatim, which already has the version, what is missing, and the fix commands) rather than "no flai on the host is connected". The badge gained a third `data-host-flai="outdated"` state alongside `connected`/`gone`. All three states, plus the ordinary connected/usable case, have their own test in each component's test file.
