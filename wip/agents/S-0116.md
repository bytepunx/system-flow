## Decisions

- Criterion 2 is detected by comparing the story's agent now with the one its last run was started with, stored on the run. It is not read from the edit notices in `.flai-cache/edits.jsonl`. Reason: a hand edit to the front matter records no notice, and the stored copy survives a restart of flai serve.
- A changed agent starting another run is a case added to ADR-0041, not a reversal of it. It is recorded as a living-design edit, with no ADR.
- The designer answered TH-0010 at 08:58Z: drop the attendance hold for stories that have room; add a restart command and button for a story whose agent drops or fails, so it gets a new agent without re-entering ready; write a new ADR superseding where needed. Two criteria were added to the story for this, and tasks T-0415 to T-0419.
- `attended_minutes` is retired because nothing reads it any more. `--attended-minutes` stays accepted, deprecated, and does nothing, so existing scripts keep working. The dashboard's settings field and the hostapi setting go. Reason: dead settings mislead operators, and removing the flag outright would break a script for no gain.
- Restart is refused for a story in ready while the in-progress limit is full. A story in progress already counts against the limit. Reason: WIP limits hold unless the operator overrides them, and the designer's criterion is framed by the limit.
- Restart needs a run from flai serve that is not running and is not waiting on an answer. A story with no run from flai serve at all is S-0115's "start". Reason: this keeps the two stories apart. S-0115 reuses the start path built here, as said on TH-0010.
