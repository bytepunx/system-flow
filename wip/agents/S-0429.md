## Decisions

- **Plan.** The planner's five tasks stand. Layers: T-1813 and T-1814 together (no path in common), then T-1815 (joins both), T-1816 (calls T-1815), T-1817 (runs the command). T-1813 and T-1814 build one Go package, so T-1814 works in its own worktree, `task/T-1814`, and its two files are copied back.
- **One `Candidate` type**, in `answer.go`, written before the first layer so both tasks share it. A decision's `Ref` is its narrative's path, an answer's the thread entry's time.
- **Topics and paths are given to `Answers` as a lookup function**, which `sources.go` builds from the repository, so the answer rule stays free of I/O for S-0433.
- **Not answers:** a resolution entry (`Resolved.` or `Resolved: ...`, 193 bare ones by the operator, plus every `S-nnnn was accepted` that archiving writes) and the threads `permission_prompt` opens (`Allow <tool> <path>?`), whose `allow` answers no question of design.
- **Seed skips a thread candidate** when an entry citing the thread names the entry's time in its body, so that several answers on one thread each get an entry and a second run writes none; issues are skipped when any entry cites them.
