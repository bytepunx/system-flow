- T-3396: a queue state that cannot be read counts as held for the preview; a real acceptance that would enqueue is refused with the enqueue's own error, as before. flai accept --resolve now finds nothing to resolve for a story held only by verify_behind_main that the acceptance would enqueue, as ADR-0308 intends.
