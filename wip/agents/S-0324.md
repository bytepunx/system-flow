## Decisions

- The planner's two tasks stand, in two layers: T-1317 (the fix, its fixture, and its test), then T-1318 (close I-0110), which waits for T-1317 because it says what fixed the issue. No layer holds two tasks, so nothing runs together.
- T-1317 is worked by the story's agent, not a task sub-agent: one function in one file and a fixture, quicker done than briefed.
- `www.md` settles the edges against markdownlint-cli2 0.20.0 rather than the GFM spec: `www.` followed by anything but the end of the paragraph is taken, any case of `www`, with micromark's domain rule (no underscore in the last two segments; a `.` or `_` that only trailing punctuation follows ends the domain).
- The `www` case is now gated on link text and an unclosed `[` as the `http` case is, and no longer consumes an invalid literal, so emphasis inside one is parsed as micromark parses it.
- The first close-out stopped on the fix itself: six lines in `wip/` carried a bare `www.` that markdownlint also reports (the T-1317 title where it is quoted, a log entry here, and one line of `wip/agents/orchestrator.md`). Each now quotes `www.` in a code span, by hand, since `flai edit` refuses a done task. The I-0117 the failed run opened for the orchestrator's line was left uncommitted and removed once that line was fixed.
