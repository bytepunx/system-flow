## Decisions

- Kept the planner's five tasks and their layers: T-1998, then T-2000, then T-2003 with T-2004, then T-2006. T-2000 waits for the ADR's key shape. T-2003 needs the manifest key. T-2004 documents both. They share no path, so they run together. T-2006 closes I-0179 last, once the fix and its test exist.
- S-0482 already installs a worktree's own flaiover dependencies in `scripts/integration.sh`. This story keeps the main checkout current, because the components host action's dev server and an unscoped `flai test` run there.
- The manifest key is `projects[].install`, with `command` (argv, run in the sub-project's folder) and `paths` (globs relative to that folder). It mirrors `tests` and `components`, and works for any lock file, such as `go.sum`.
- The install runs after the acceptance commit. A failure warns and names the command to run, never fails the acceptance: the merge is committed by then.
- T-1998 is written here rather than by a sub-agent, because the ADR is where these decisions are recorded.
