## Decisions

- Plan, three layers. Layer 1: T-1221 checks the cosign, GoReleaser, and attestation claims, since the runbook's commands and the workflow's flags and versions depend on what it finds. Layer 2: T-1222 (runbook) and T-1223 (GoReleaser and workflow) run together, with no path in common, each after T-1221. Layer 3: T-1224 (`design/tech/ci.md`) after T-1223, which pins the versions it lists; T-1225 (the key constants) after T-1222, because the key is the one the operator generates with that runbook.
- The story's folder touches `flai/internal/buildinfo` and `docs/operators` are narrowed to the files the tasks name.
- The repository is private and the organisation is on the Team plan (`gh api`, 2026-10-07): T-1221 checks whether artifact attestations run there before T-1223 adds the step.
- T-1221 found attestations and environment required reviewers are public-only on Team. Worked on the recommendations put on TH-0324, pending the operator: the attestation step is skipped while the repository is private, and the key lives in an environment `release` that only release tags deploy to, with a tag ruleset.
- cosign is pinned to v3.1.3 through `sigstore/cosign-installer@v4.1.2`: v3 needs `--use-signing-config=false --new-bundle-format=false` beside `--tlog-upload=false` to write a plain signature, v4 drops those flags, and the installer has no `v4` tag.
- `scripts/flai-snapshot.sh` passes `--skip=sign`: `--snapshot` does not skip signing, and the `signs` entry's `if` is GoReleaser Pro only.
- T-1222 and T-1223 ran together; T-1223's files were committed by hand before `flai task done T-1222`, because task done commits everything in the worktree and would have put both tasks in one commit.
- T-1225 plan: the public key is the file `flai/internal/buildinfo/cosign.pub`, embedded with `go:embed` as the package's PEM, so that GoReleaser's `release.extra_files` publishes the same bytes as a release asset; flaiover's `release.ts` holds the PEM as a constant and its test reads the Go package's file from the checkout to check the two are identical.
