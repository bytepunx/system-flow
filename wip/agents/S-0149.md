# S-0149 Provide briefs in cases where large files are part of context

## Context

The follow-up TH-0032 asked for: stories and tasks that write out a path such as `design/system/flai-cli.md` (86 KB) as a file to update load the whole file into the context pack, which is what takes packs furthest over the 80 KB budget. ## Decisions

- A path written out is briefed only when the document is larger than an eighth of the budget (10 KB at 80 KB); smaller ones still load whole, because their brief would cost nearly as much as the body and the agent would have to fetch it anyway. The criterion says "large referenced files", the goal says every written-out path; the threshold reconciles the two. Tied to the budget so a project that raises `prime.budget` briefs less, without a new setting.
- S-0149 overlaps S-0148 (in progress) on `design/system/agent-context.md` and `docs/users`. Edits there are kept to the pack's rules; whichever story is accepted second syncs.

- Commits are made per task, as the operator's start instruction says ("Commit each task"), over `git.md`'s "not at task boundaries"; recent stories did the same.

- A document briefed for its size is not followed by the one link step except from sections its topics select, as for any brief (added to ADR-0050 in the same story).
