# S-0344 flai dashboard restart starts the container's tag again, so a newer image a check pulled under a floating tag is started without an upgrade

## Context

Remediates I-0116: `flai dashboard restart` and `flai host`'s watch start the container's tag again, so a newer image a check pulled under a floating tag is started without an upgrade. ADR-0118 §1 says a restart keeps the release that runs.

## Current state

T-1360 in progress: `flai dashboard restart` starts the running container's image ID, labelled with its reference. The fix is recorded in Decisions.

## Next steps

1. Review T-1360's work, close it with `flai task done`, and test `flai/cmd`.
2. T-1361: the watch records the image ID and restarts from it.
3. T-1362: the documents, then close I-0116.
4. Close out and move to review.

## Decisions

- Fix, as the planner recommended: a restart of a running dashboard starts the image ID the container runs (`{{.Image}}`), never its tag. Each dashboard container carries a label, `io.bytepunx.flai.ref`, with the reference it was started for, and `containerInfo` prefers that label over `{{.Config.Image}}`, which is the ID after such a restart. So status, versions, and restart's output still name the tag. Rejected: starting the tag while it still names the running image and the ID only once it has moved. It keeps the tag without a label, but shows `sha256:...` exactly when the tag has moved, and checks then starts in two steps.
- The watch's record gains `image`, the image ID the container runs, read after each start. The watch restarts from it, labelled with the record's `ref`; a record an older flai wrote, with no `image`, restarts from `ref` as before, and an `image` no longer local (pruned) falls back to `ref` with a warning.
- The planner's three tasks stand. Layers: T-1360 (restart and the shared rule), then T-1361 (the watch, which reuses T-1360's rule), then T-1362 (documents and closing I-0116, which describe both). Each waits for the one before because it builds on its code or describes it; none run together.
