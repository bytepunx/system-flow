## Decisions

- ADR-0064 refines ADR-0043. Restart covers a story with no run here, and `agent start` stays for ready stories. Reason: restart is already for "an in-progress story whose agent is gone".
- The narrative records `host` (the Notes asked whether to decide this here). Reason: without it a story begun on this host outside flai serve cannot be told from one begun elsewhere.
- A story in review gets no begun-elsewhere entry or Start agent. Reason: restart takes only ready or in-progress stories (ADR-0043), and the criteria name a story in progress. The explorer noted that the review page has no agent block.
- The MCP tools need no guard change. Reason: `flai guard` refuses every MCP tool not in `guard.MCPReads` to a sub-agent.
- The operator's prompt says to commit each task, while `git.md` says commit when a story lands. Following the operator.
