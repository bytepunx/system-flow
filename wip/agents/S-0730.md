- Kept the planner's four tasks and three layers (TH-1173, approved by the orchestrator): T-3319 alone; T-3320 after T-3319, since it reads Call.Whole and Call.Content and shares call.go; T-3321 and T-3322 after T-3320, since both name the rule's final words, and they run together, with no path in common.
- T-3319 done by the story's agent, not a sub-agent: about 20 lines, quicker than briefing one (delegation.md, don't delegate what is slower).
- Call carries Whole and Content rather than Content alone, so that a Write with empty content still counts as replacing the file whole.
- The rule (T-3320): any caller's whole-file Write, Claude Code Write or OpenCode write, to an epic, story, or task file under wip/kanban or wip/archive/kanban, in the main checkout or a story's worktree, is refused unless workitem.ParseItem reads its content as an item whose id and type are the ones the file's name and folder give, and the file already exists. Edit and MultiEdit, which change part of a file, stay as they are. An ADR records it, since it is a rule a tool enforces (decisions.md).
- Changed the T-3320 rule from the earlier decision: it no longer refuses a Write that makes a new item file with matching front matter. The guard reads nothing from disk for file writes, and judges the file by its name and folder (kanban/<epics|stories|tasks>/<ID>-<slug>.md, the archive's included), so the rule needs no I/O and no change to flai/cmd. Making items by hand stays a convention in tooling.md. ADR-0298 records it under Consequences.
- T-3320 done by the story's agent, not a sub-agent, for the same reason as T-3319. ADR-0298 (accepted, refines ADR-0060 and ADR-0102) was written first, so that the refusal names its number; T-3320's close commits it, since no other open task covers design/adrs.
- The rule runs in Decide for every caller, after the host-configuration rule and before the sub-agent and role rules, so that a story's agent, its sub-agents, and strategic agents meet it alike.
- T-3321 by a task sub-agent; reviewed its diff. I replaced the elided output in the user guide's example with the real refusal, after running the example with bin/flai guard (exit 2).
- Criteria 1 and 2 ticked: TestTheGuardRefusesAWriteThatReplacesAWorkItemWithWhatIsNotIt reproduces I-0352's Write, the guide's example shows the built guard refusing it, and I-0352 is closed with a reason naming items.go and ADR-0298.
