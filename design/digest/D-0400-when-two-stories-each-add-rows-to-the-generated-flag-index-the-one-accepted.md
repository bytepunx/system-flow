# D-0400 When two stories each add rows to the generated flag index, the one accepted second regenerates it with make flai-reference rather than merging rows by hand

`docs/operators/settings.md`'s flag table and `docs/users/flai-reference.md` are generated by `make flai-reference`. Eight stories (S-0332 to S-0372) added flags in parallel and claimed the same files. S-0334 "agreed with S-0232 that both merge cleanly, and told S-0341 whichever is accepted second regenerates it", and S-0347 found the file "merges cleanly" after regenerating.

So a story that meets another on these files does not hand-merge rows: after its sync it runs `make flai-reference` and commits the result.
