Every base names an exact version, `GO_VERSION`, `GO_ALPINE_VERSION`, and `ALPINE_VERSION` by default, and dependabot's `docker` entry watches `flai/images/bedrock` and `flai/images/system-flow` beside `flaiover`, so the pins move weekly (S-0630); `scripts/ci-pins.sh` fails a tag that is not exact. All are unstamped and unsigned, and built or published by no workflow; pilot ships in the image only, not in flai's GoReleaser release. `scripts/agent-container.sh S-nnnn` runs a story's agent in the second, with the main checkout's `.git` read-only and the story's registration read-write, and its `wip/` and `system-flow.yaml` read-only and `.flai-cache/verify` read-write, mounted beside the worktree, as the harness mounts them ([ADR-0246](../adrs/0246-a-container-that-runs-a-story-s-agent-mounts-the-main-checkout-s-git-read-only.md)): it feeds pilot a start request and passes the MCP server's URL, token, and Host by `docker run -e NAME` from its own environment, never in an argument (S-0505, S-0507, E-0029, [agent-adapters.md](../system/agent-adapters.md#a-container-harness-of-flais-own)) |

It never mounts the Docker socket, the home, `~/.flai`, or the main checkout's other files; every commit is the host's. Before the start `flai serve` asks `docker image inspect` for the image and reads Claude Code's version with `docker run --rm --network none --entrypoint claude <image> --version`; with the MCP server on loopback and a network other than `host`, it asks `docker info --format '{{.OperatingSystem}}'` once, and on an engine other than Docker Desktop refuses the start, naming the gateway `docker network inspect <network>` gives ([ADR-0269](../adrs/0269-flai-serve-refuses-a-container-start-whose-http-mcp-server-listens-on-loopback.md)); a stop runs `docker stop` on the container's name ([flai-cli.md](../system/flai-cli.md#the-container-harness-s-0508)). Such a story's close-out verify and the operator's checks run in containers of their own from the same image, `flai-closeout-<story>-<stamp>` and `flai-check-<story>-<stamp>-<n>`, with the first six mounts and no login, cache folder, MCP variable, provider key, or `--add-host`; the close-out's commit and sync stay on the host ([ADR-0274](../adrs/0274-the-close-out-of-a-story-whose-agent-runs-in-a-container-runs-its-verify-in.md)) |

## Why

The brief requires a published image the CLI can download and run. Docker avoids asking every user to install Node. The container holds the web server and nothing else: the board is operable from the browser because the server asks `flai serve` on the host for every read and write (ADR-0029), so no repository is mounted ([ADR-0031](../adrs/0031-the-dashboard-s-container-holds-nothing-of-the-project-a-port-and-two-secrets.md); until S-0077 it was, read-write, at its host path, ADR-0022). It runs as a non-root user with the host's UID passed via `--user`, because the two secret files it is handed are readable by that user alone.

Decision: [ADR 0007](../adrs/0007-sveltekit-spa-with-node-adapter-in-docker.md).
